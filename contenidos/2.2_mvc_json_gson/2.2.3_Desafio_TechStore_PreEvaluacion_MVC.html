Fase 2 — Misión 1: Cargar el JSON en DispositivoManager Deserializar un arreglo polimórfico con JsonObject[] y almacenar los objetos en memoria

Abre model/DispositivoManager.java. Como Dispositivo es una clase abstracta, Gson no puede hacer gson.fromJson(lector, Dispositivo[].class) directamente. En su lugar, usamos la estrategia vista en clases con JsonObject[]:

  1. Declara un atributo private ArrayList<Dispositivo> dispositivos = new ArrayList<>();.
  2. En el constructor public DispositivoManager(), invoca a tu método cargarDatos().
  3. Dentro de cargarDatos():
    • Abre el flujo hacia "/dispositivos.json" con getClass().getResourceAsStream("/dispositivos.json") e InputStreamReader.
    • Convierte el archivo en un arreglo JsonObject[] arregloJson = gson.fromJson(reader, JsonObject[].class);.
    • Recorre cada JsonObject con un ciclo for y evalúa jObject.get("tipo").getAsString():
      • Si es igual a "notebook", deserialízalo con gson.fromJson(jObject, Notebook.class) y agrégalo a dispositivos.
      • Si es igual a "smartphone", deserialízalo con gson.fromJson(jObject, Smartphone.class) y agrégalo a dispositivos.
  4. Agrega dos métodos públicos:
    • public ArrayList<Dispositivo> getDispositivos() que retorne la lista.
    • public void agregarDispositivo(Dispositivo nuevo) que haga dispositivos.add(nuevo).
💡 Pista de sintaxis: ¿Cómo se lee el campo "tipo" desde un JsonObject? 
Gson gson = new Gson();
JsonObject[] arregloJson = gson.fromJson(reader, JsonObject[].class);

for (JsonObject obj : arregloJson) {
    String tipo = obj.get("tipo").getAsString();
    if (tipo.equals("notebook")) {
        Notebook nb = gson.fromJson(obj, Notebook.class);
        dispositivos.add(nb);
    } else if (tipo.equals("smartphone")) {
        Smartphone sp = gson.fromJson(obj, Smartphone.class);
        dispositivos.add(sp);
    }
}

Fase 3 — Misión 2: Conectar DispositivoController Mantener la separación de responsabilidades entre la Vista y el Modelo

Abre controller/DispositivoController.java. Recuerda la regla de oro de MVC: la vista nunca instancia ni llama directamente al Manager; siempre se comunica a través del Controlador.

Tu clase DispositivoController debe incluir:

  1. Un atributo private DispositivoManager manager = new DispositivoManager();.
  2. Un método public ArrayList<Dispositivo> obtenerDispositivos() que retorne manager.getDispositivos().
  3. Un método (o dos métodos específicos) para registrar un nuevo equipo en el manager. Por ejemplo:
    • public void agregarDispositivo(Dispositivo nuevo) que llame a manager.agregarDispositivo(nuevo);, o bien
    • Un método que reciba los datos del formulario, calcule el nuevo id (por ejemplo, manager.getDispositivos().size() + 1), instancie Notebook o Smartphone según corresponda y lo envíe al manager.

Fase 5 — Misión 4: Formulario para agregar un nuevo Dispositivo Capturar los datos del usuario, instanciar la clase hija y refrescar el TableView

En la parte inferior de CatalogoView.java (bloque // TODO 3), construye un formulario que permita agregar un nuevo Notebook o Smartphone y verlo reflejado de inmediato en el TableView.

Requisitos del formulario

  • Selector de tipo: un ComboBox<String> con las opciones "Notebook" y "Smartphone" (o un TextField donde se escriba el tipo).
  • Campos comunes: TextField para Marca, Modelo y Precio.
  • Campos específicos:
    • Si es Notebook: ramGb (int) y procesador (String).
    • Si es Smartphone: almacenamientoGb (int) y camaraMp (int).
  • Botón "Agregar Dispositivo": al hacer clic (setOnAction):
    1. Lee los valores de los controles y convierte los valores numéricos usando Integer.parseInt(...) dentro de un bloque try-catch.
    2. Crea la instancia de Notebook o Smartphone y pásala al controlador.
    3. Actualiza los elementos de la tabla con tabla.setItems(FXCollections.observableArrayList(controller.obtenerDispositivos())); (o añadiendo el objeto a la lista observable de la tabla).
    4. Limpia los TextField con .clear() para dejar listo el siguiente ingreso.
💡 Pista: ¿Cómo usar un ComboBox<String> en JavaFX para elegir entre Notebook y Smartphone? 
ComboBox<String> cmbTipo = new ComboBox<>();
cmbTipo.getItems().addAll("Notebook", "Smartphone");
cmbTipo.setValue("Notebook"); // Valor seleccionado por defecto

// Luego, dentro del setOnAction del botón:
String tipoSeleccionado = cmbTipo.getValue();

Fase 6 — Checklist de Autoevaluación y Verificación DUA Comprueba que tu solución cumple todos los criterios antes de hacer push
