Fase 2 — Implementación del modelo polimórfico Escribir Material, Libro y Revista en el paquete model

Modelo · Nuevo 📄 model/Material.java · 📍 Archivo completo
¿Por qué existe esta clase? Define el contrato base para cualquier lectura de la biblioteca. Es abstract porque en la realidad no existe un "material genérico": nadie pide prestado "un material", piden un Libro o una Revista.
Bloque de código
¿Por qué está y qué resuelve?
package com.hachimakidev.bibliotech.model;

public abstract class Material {

    private String titulo;
    private String autor;
    private int cantidadDisponible;

Atributos protegidos: Son comunes a todo material. Encapsulados como privados para evitar que la vista u otra clase altere el stock directamente.

    public Material() {}

    public Material(String titulo, String autor, int cantidadDisponible) {
        this.titulo = titulo;
        this.autor = autor;
        this.cantidadDisponible = cantidadDisponible;
    }

Constructor vacío: Requerido por Gson para crear objetos mediante reflexión.

Constructor con parámetros: Reutilizado por las subclases usando super().

    public abstract int calcularDiasPrestamo();
    public abstract String getTipo();
    public abstract String getDetalle();

    public int getDiasPrestamo() {
        return calcularDiasPrestamo();
    }

El contrato polimórfico: Obliga a que cada hijo defina cuántos días se presta y cómo se describe.

El puente con TableView: La tabla JavaFX buscará un getter con convención JavaBean. getDiasPrestamo() llama internamente al método abstracto calcularDiasPrestamo().

¿Qué pasa si borro getDiasPrestamo()?

La columna "Días" de la TableView saldrá en blanco, porque PropertyValueFactory("diasPrestamo") busca exactamente un método llamado getDiasPrestamo().

    public void prestarEjemplar() throws PrestamoException {
        if (cantidadDisponible <= 0) {
            throw new PrestamoException("No quedan ejemplares disponibles de \"" + titulo + "\".");
        }
        cantidadDisponible--;
    }

Regla de negocio en el Modelo: Si no queda stock, el objeto se defiende lanzando una excepción propia. No dejamos que el stock quede en números negativos.

package com.hachimakidev.bibliotech.model;

public abstract class Material {

    private String titulo;
    private String autor;
    private int cantidadDisponible;

    public Material() {}

    public Material(String titulo, String autor, int cantidadDisponible) {
        this.titulo = titulo;
        this.autor = autor;
        this.cantidadDisponible = cantidadDisponible;
    }

    public String getTitulo() { return titulo; }
    public String getAutor() { return autor; }
    public int getCantidadDisponible() { return cantidadDisponible; }

    public abstract int calcularDiasPrestamo();
    public abstract String getTipo();
    public abstract String getDetalle();

    public int getDiasPrestamo() {
        return calcularDiasPrestamo();
    }

    public void prestarEjemplar() throws PrestamoException {
        if (cantidadDisponible <= 0) {
            throw new PrestamoException("No quedan ejemplares disponibles de \"" + titulo + "\".");
        }
        cantidadDisponible--;
    }
}

Fase 3 — El reto del JSON compuesto con Gson Por qué Gson no puede instanciar clases abstractas y cómo resolverlo elegantemente

Pregunta trampa: En la Parte 1 hicimos gson.fromJson(reader, User[].class). ¿Podríamos hacer ahora gson.fromJson(reader, Material[].class)?

¡NO! Si lo intentas, Gson arrojará una excepción en tiempo de ejecución: java.lang.InstantiationException: Material is abstract. Como Material es abstracto, Java no puede hacer new Material() para llenarlo con los datos del archivo.

La solución limpia y profesional para este nivel es estructurar catalogo.json como un objeto compuesto con dos listas tipadas, y crear una pequeña clase molde llamada CatalogoJson:

package com.hachimakidev.bibliotech.model;

import java.io.InputStream;
import java.io.InputStreamReader;
import java.util.ArrayList;

import com.google.gson.Gson;

public class MaterialManager {

    private ArrayList<Material> lista_materiales = new ArrayList<>();
    private boolean datos_cargados = false;

    public MaterialManager() {
        cargarDatos();
    }

    private void cargarDatos() {
        try {
            InputStream stream = getClass().getResourceAsStream("/catalogo.json");

            InputStreamReader reader = new InputStreamReader(stream);

            Gson gson = new Gson();
            CatalogoJson catalogo = gson.fromJson(reader, CatalogoJson.class);

            for (Libro libro : catalogo.getLibros()) {
                lista_materiales.add(libro);
            }
            for (Revista revista : catalogo.getRevistas()) {
                lista_materiales.add(revista);
            }

            datos_cargados = true;

        } catch (Exception e) {
            System.out.println("Error al cargar catalogo.json: " + e);
        }
    }

    public boolean isDatosCargados() {
        return datos_cargados;
    }

    public ArrayList<Material> obtenerCatalogo() {
        return lista_materiales;
    }
}

package com.hachimakidev.bibliotech.model;

import java.time.LocalDate;

public class Prestamo {

    private User usuario;
    private Material material;
    private LocalDate fechaPrestamo;
    private LocalDate fechaDevolucion;

    public Prestamo(User usuario, Material material) {
        this.usuario = usuario;
        this.material = material;
        this.fechaPrestamo = LocalDate.now();
        this.fechaDevolucion = fechaPrestamo.plusDays(material.calcularDiasPrestamo());
    }

Unión de los dos mundos: Relaciona un User con un Material.

Polimorfismo en fechas: material.calcularDiasPrestamo() sumará 14 días si es un libro, o 3 días si es una revista, usando el API moderna java.time.LocalDate.

public class CatalogoController {

    private MaterialManager manager_materiales;
    private UserManager manager_usuarios;
    private ArrayList<Prestamo> lista_prestamos = new ArrayList<>();

    public CatalogoController() {
        manager_materiales = new MaterialManager();
        manager_usuarios = new UserManager();
    }

El orquestador de MVC: El controlador es el único que conoce a ambos managers (usuarios y materiales). La vista jamás toca los managers directamente.

    public Prestamo prestar(String rut_ingresado, Material material) throws PrestamoException {

        if (material == null) {
            throw new PrestamoException("Selecciona un material en la tabla.");
        }

        String rut_limpio = rut_ingresado.trim();
        if (rut_limpio.isEmpty()) {
            throw new PrestamoException("Escribe el RUT de quien pide el préstamo.");
        }

        User usuario = manager_usuarios.buscarPorRut(rut_limpio);
        if (usuario == null) {
            throw new PrestamoException("No existe un usuario con RUT " + rut_limpio + ".");
        }

        material.prestarEjemplar();

        Prestamo prestamo = new Prestamo(usuario, material);
        lista_prestamos.add(prestamo);
        return prestamo;
    }

Validaciones escalonadas:

1. ¿Hay material seleccionado?
2. ¿El RUT está en blanco?
3. ¿El usuario existe en la biblioteca?
4. Si todo es válido, material.prestarEjemplar() descuenta el stock.
5. Retorna el nuevo Prestamo creado.

¿Tu tabla aparece con columnas vacías?

Revisa la palabra exacta dentro de new PropertyValueFactory<>("..."). Debe coincidir exactamente con el getter: si en la clase dice getTitulo(), la propiedad debe decir "titulo" en minúscula. Si escribes "Titulo" con mayúscula, JavaFX no encontrará el método y dejará la celda vacía.

package com.hachimakidev.bibliotech.view;

import java.time.format.DateTimeFormatter;

import com.hachimakidev.bibliotech.controller.CatalogoController;

import javafx.collections.FXCollections;

public class CatalogoView {

    public VBox catalogo() {

        CatalogoController controller = new CatalogoController();

        // ---------- 1. La tabla ----------
        TableView<Material> tbl_catalogo = new TableView<>();
        tbl_catalogo.setPlaceholder(new Label("No hay materiales para mostrar."));

        TableColumn<Material, String> col_tipo = new TableColumn<>("Tipo");
        col_tipo.setCellValueFactory(new PropertyValueFactory<>("tipo"));

        TableColumn<Material, String> col_titulo = new TableColumn<>("Título");
        col_titulo.setCellValueFactory(new PropertyValueFactory<>("titulo"));
        col_titulo.setPrefWidth(220);

        TableColumn<Material, String> col_autor = new TableColumn<>("Autor");
        col_autor.setCellValueFactory(new PropertyValueFactory<>("autor"));
        col_autor.setPrefWidth(170);

        TableColumn<Material, String> col_detalle = new TableColumn<>("Detalle");
        col_detalle.setCellValueFactory(new PropertyValueFactory<>("detalle"));
        col_detalle.setPrefWidth(150);

        TableColumn<Material, Integer> col_dias = new TableColumn<>("Días");
        col_dias.setCellValueFactory(new PropertyValueFactory<>("diasPrestamo"));

        TableColumn<Material, Integer> col_stock = new TableColumn<>("Disponibles");
        col_stock.setCellValueFactory(new PropertyValueFactory<>("cantidadDisponible"));

        tbl_catalogo.getColumns().add(col_tipo);
        tbl_catalogo.getColumns().add(col_titulo);
        tbl_catalogo.getColumns().add(col_autor);
        tbl_catalogo.getColumns().add(col_detalle);
        tbl_catalogo.getColumns().add(col_dias);
        tbl_catalogo.getColumns().add(col_stock);

        tbl_catalogo.setItems(FXCollections.observableArrayList(controller.obtenerCatalogo()));

        // ---------- 2. El formulario de préstamo ----------
        Label lbl_rut = new Label("RUT del usuario:");
        TextField txf_rut = new TextField();
        txf_rut.setPromptText("Ej: 12345678-9");
        Button btn_prestar = new Button("Prestar seleccionado");

        Label lbl_estado = new Label();

        if (!controller.datosDisponibles()) {
            lbl_estado.setText("Error: no se pudieron cargar el catálogo o los usuarios.");
            btn_prestar.setDisable(true);
        }

        // ---------- 3. El evento del botón ----------
        btn_prestar.setOnAction(evento -> {

            Material seleccionado = tbl_catalogo.getSelectionModel().getSelectedItem();

            try {
                Prestamo prestamo = controller.prestar(txf_rut.getText(), seleccionado);

                tbl_catalogo.refresh();

                DateTimeFormatter formato = DateTimeFormatter.ofPattern("dd-MM-yyyy");
                String mensaje = prestamo.getUsuario().getNombre()
                        + " se lleva \"" + seleccionado.getTitulo() + "\".\n"
                        + "Plazo: " + seleccionado.calcularDiasPrestamo() + " días.\n"
                        + "Devolver el: " + prestamo.getFechaDevolucion().format(formato);

                mostrarAlerta(Alert.AlertType.INFORMATION, "Préstamo registrado", mensaje);

            } catch (PrestamoException e) {
                mostrarAlerta(Alert.AlertType.WARNING, "No se pudo prestar", e.getMessage());
            }
        });

        // ---------- 4. Armar la pantalla ----------
        HBox fila_prestamo = new HBox(10, lbl_rut, txf_rut, btn_prestar);
        VBox box = new VBox(10, tbl_catalogo, fila_prestamo, lbl_estado);
        box.setPadding(new Insets(20));

        return box;
    }

    private void mostrarAlerta(Alert.AlertType tipo, String titulo, String mensaje) {
        Alert alerta = new Alert(tipo);
        alerta.setTitle(titulo);
        alerta.setHeaderText(null);
        alerta.setContentText(mensaje);
        alerta.showAndWait();
    }
}

¿Qué hace setTabClosingPolicy(UNAVAILABLE)?

Por defecto JavaFX permite que el usuario cierre pestañas con una cruz ('x'). Como esta es una app de gestión, no queremos que el operador cierre accidentalmente la pantalla de catálogo.

Material / Libro

  • 1. Evento en la Vista (CatalogoView): btn_prestar.setOnAction() extrae el objeto seleccionado de la TableView y el texto del TextField.
  • 2. Petición al Controlador (CatalogoController): La vista llama a controller.prestar(rut, material).
  • 3. Validación y Búsqueda (CatalogoController): El controlador limpia el RUT con .trim() y consulta a manager_usuarios.buscarPorRut(). Si no existe, lanza PrestamoException.
  • 4. Regla de negocio en el Modelo (Material): Se invoca material.prestarEjemplar(). Si cantidadDisponible <= 0, el modelo se defiende lanzando una excepción. Si hay stock, decrementa en 1.
  • 5. Instanciación Polimórfica (Prestamo): El constructor de Prestamo invoca material.calcularDiasPrestamo(). Según sea Libro o Revista, Java ejecuta dinámicamente la versión que corresponde.
  • 6. Respuesta a la Vista (CatalogoView): La vista recibe el objeto Prestamo, refresca la tabla con tbl_catalogo.refresh() y despliega la alerta de confirmación con la fecha calculada.

package com.hachimakidev.bibliotech.model;

public abstract class Material {

    private String titulo;
    private String autor;
    private int cantidadDisponible;

    public Material() {}

    public Material(String titulo, String autor, int cantidadDisponible) {
        this.titulo = titulo;
        this.autor = autor;
        this.cantidadDisponible = cantidadDisponible;
    }

    public String getTitulo() { return titulo; }
    public String getAutor() { return autor; }
    public int getCantidadDisponible() { return cantidadDisponible; }

    public abstract int calcularDiasPrestamo();
    public abstract String getTipo();
    public abstract String getDetalle();

    public int getDiasPrestamo() {
        return calcularDiasPrestamo();
    }

    public void prestarEjemplar() throws PrestamoException {
        if (cantidadDisponible <= 0) {
            throw new PrestamoException("No quedan ejemplares disponibles de \"" + titulo + "\".");
        }
        cantidadDisponible--;
    }
}

package com.hachimakidev.bibliotech.model;

import java.io.InputStream;
import java.io.InputStreamReader;
import java.util.ArrayList;

import com.google.gson.Gson;

public class MaterialManager {

    private ArrayList<Material> lista_materiales = new ArrayList<>();
    private boolean datos_cargados = false;

    public MaterialManager() {
        cargarDatos();
    }

    private void cargarDatos() {
        try {
            InputStream stream = getClass().getResourceAsStream("/catalogo.json");

            InputStreamReader reader = new InputStreamReader(stream);

            Gson gson = new Gson();
            CatalogoJson catalogo = gson.fromJson(reader, CatalogoJson.class);

            for (Libro libro : catalogo.getLibros()) {
                lista_materiales.add(libro);
            }
            for (Revista revista : catalogo.getRevistas()) {
                lista_materiales.add(revista);
            }

            datos_cargados = true;

        } catch (Exception e) {
            System.out.println("Error al cargar catalogo.json: " + e);
        }
    }

    public boolean isDatosCargados() {
        return datos_cargados;
    }

    public ArrayList<Material> obtenerCatalogo() {
        return lista_materiales;
    }
}

import java.time.LocalDate;

public class Prestamo {

    private User usuario;
    private Material material;
    private LocalDate fechaPrestamo;
    private LocalDate fechaDevolucion;

    public Prestamo(User usuario, Material material) {
        this.usuario = usuario;
        this.material = material;
        this.fechaPrestamo = LocalDate.now();
        this.fechaDevolucion = fechaPrestamo.plusDays(material.calcularDiasPrestamo());
    }

    public User getUsuario() { return usuario; }
    public Material getMaterial() { return material; }
    public LocalDate getFechaPrestamo() { return fechaPrestamo; }
    public LocalDate getFechaDevolucion() { return fechaDevolucion; }
}

package com.hachimakidev.bibliotech.controller;

import java.util.ArrayList;

import com.hachimakidev.bibliotech.model.Material;
import com.hachimakidev.bibliotech.model.MaterialManager;
import com.hachimakidev.bibliotech.model.Prestamo;
import com.hachimakidev.bibliotech.model.PrestamoException;
import com.hachimakidev.bibliotech.model.User;
import com.hachimakidev.bibliotech.model.UserManager;

public class CatalogoController {

    private MaterialManager manager_materiales;
    private UserManager manager_usuarios;
    private ArrayList<Prestamo> lista_prestamos = new ArrayList<>();

    public CatalogoController() {
        manager_materiales = new MaterialManager();
        manager_usuarios = new UserManager();
    }

    public boolean datosDisponibles() {
        return manager_materiales.isDatosCargados() && manager_usuarios.isDatosCargados();
    }

    public ArrayList<Material> obtenerCatalogo() {
        return manager_materiales.obtenerCatalogo();
    }

    public Prestamo prestar(String rut_ingresado, Material material) throws PrestamoException {

        if (material == null) {
            throw new PrestamoException("Selecciona un material en la tabla.");
        }

        String rut_limpio = rut_ingresado.trim();
        if (rut_limpio.isEmpty()) {
            throw new PrestamoException("Escribe el RUT de quien pide el préstamo.");
        }

        User usuario = manager_usuarios.buscarPorRut(rut_limpio);
        if (usuario == null) {
            throw new PrestamoException("No existe un usuario con RUT " + rut_limpio + ".");
        }

        material.prestarEjemplar();

        Prestamo prestamo = new Prestamo(usuario, material);
        lista_prestamos.add(prestamo);
        return prestamo;
    }
}

package com.hachimakidev.bibliotech.view;

import java.time.format.DateTimeFormatter;

import com.hachimakidev.bibliotech.controller.CatalogoController;
import com.hachimakidev.bibliotech.model.Material;
import com.hachimakidev.bibliotech.model.Prestamo;
import com.hachimakidev.bibliotech.model.PrestamoException;

import javafx.collections.FXCollections;
import javafx.geometry.Insets;
import javafx.scene.control.Alert;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;
import javafx.scene.control.TextField;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;

public class CatalogoView {

    public VBox catalogo() {

        CatalogoController controller = new CatalogoController();

        // ---------- 1. La tabla ----------
        TableView<Material> tbl_catalogo = new TableView<>();
        tbl_catalogo.setPlaceholder(new Label("No hay materiales para mostrar."));

        TableColumn<Material, String> col_tipo = new TableColumn<>("Tipo");
        col_tipo.setCellValueFactory(new PropertyValueFactory<>("tipo"));

        TableColumn<Material, String> col_titulo = new TableColumn<>("Título");
        col_titulo.setCellValueFactory(new PropertyValueFactory<>("titulo"));
        col_titulo.setPrefWidth(220);

        TableColumn<Material, String> col_autor = new TableColumn<>("Autor");
        col_autor.setCellValueFactory(new PropertyValueFactory<>("autor"));
        col_autor.setPrefWidth(170);

        TableColumn<Material, String> col_detalle = new TableColumn<>("Detalle");
        col_detalle.setCellValueFactory(new PropertyValueFactory<>("detalle"));
        col_detalle.setPrefWidth(150);

        TableColumn<Material, Integer> col_dias = new TableColumn<>("Días");
        col_dias.setCellValueFactory(new PropertyValueFactory<>("diasPrestamo"));

        TableColumn<Material, Integer> col_stock = new TableColumn<>("Disponibles");
        col_stock.setCellValueFactory(new PropertyValueFactory<>("cantidadDisponible"));

        tbl_catalogo.getColumns().add(col_tipo);
        tbl_catalogo.getColumns().add(col_titulo);
        tbl_catalogo.getColumns().add(col_autor);
        tbl_catalogo.getColumns().add(col_detalle);
        tbl_catalogo.getColumns().add(col_dias);
        tbl_catalogo.getColumns().add(col_stock);

        tbl_catalogo.setItems(FXCollections.observableArrayList(controller.obtenerCatalogo()));

        // ---------- 2. El formulario de préstamo ----------
        Label lbl_rut = new Label("RUT del usuario:");
        TextField txf_rut = new TextField();
        txf_rut.setPromptText("Ej: 12345678-9");
        Button btn_prestar = new Button("Prestar seleccionado");

        Label lbl_estado = new Label();

        if (!controller.datosDisponibles()) {
            lbl_estado.setText("Error: no se pudieron cargar el catálogo o los usuarios.");
            btn_prestar.setDisable(true);
        }

        // ---------- 3. El evento del botón ----------
        btn_prestar.setOnAction(evento -> {

            Material seleccionado = tbl_catalogo.getSelectionModel().getSelectedItem();

            try {
                Prestamo prestamo = controller.prestar(txf_rut.getText(), seleccionado);

                tbl_catalogo.refresh();

                DateTimeFormatter formato = DateTimeFormatter.ofPattern("dd-MM-yyyy");
                String mensaje = prestamo.getUsuario().getNombre()
                        + " se lleva \"" + seleccionado.getTitulo() + "\".\n"
                        + "Plazo: " + seleccionado.calcularDiasPrestamo() + " días.\n"
                        + "Devolver el: " + prestamo.getFechaDevolucion().format(formato);

                mostrarAlerta(Alert.AlertType.INFORMATION, "Préstamo registrado", mensaje);

            } catch (PrestamoException e) {
                mostrarAlerta(Alert.AlertType.WARNING, "No se pudo prestar", e.getMessage());
            }
        });

        // ---------- 4. Armar la pantalla ----------
        HBox fila_prestamo = new HBox(10, lbl_rut, txf_rut, btn_prestar);
        VBox box = new VBox(10, tbl_catalogo, fila_prestamo, lbl_estado);
        box.setPadding(new Insets(20));

        return box;
    }

    private void mostrarAlerta(Alert.AlertType tipo, String titulo, String mensaje) {
        Alert alerta = new Alert(tipo);
        alerta.setTitle(titulo);
        alerta.setHeaderText(null);
        alerta.setContentText(mensaje);
        alerta.showAndWait();
    }
}
