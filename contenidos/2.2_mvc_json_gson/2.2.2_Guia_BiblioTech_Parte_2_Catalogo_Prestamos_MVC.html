El razonamiento orientado a objetos

Al analizar los datos y el encargo notamos tres cosas:

  • Tanto libros como revistas tienen titulo y cantidadDisponible.
  • Los libros se prestan por 14 días y las revistas por 3 días.
  • Nadie va a la biblioteca a pedir "un material genérico": siempre piden un Libro o una Revista. Por eso la clase padre debe ser abstracta.

Paso 2.1 — Clase padre abstracta: Material.java

Crea src/main/java/com/hachimakidev/bibliotech/model/Material.java:

Modelo · Clase base abstracta 📄 model/Material.java 
package com.hachimakidev.bibliotech.model;

public abstract class Material {

    private String titulo;
    private int cantidadDisponible;

    public Material() {}

    public Material(String titulo, int cantidadDisponible) {
        this.titulo = titulo;
        this.cantidadDisponible = cantidadDisponible;
    }

    // Métodos polimórficos: cada subclase define su tipo y sus días de préstamo
    public abstract String getTipo();
    public abstract int getDiasPrestamo();

    // Regla de negocio: descuenta un ejemplar si queda stock disponible
    public boolean prestar() {
        if (cantidadDisponible > 0) {
            cantidadDisponible--;
            return true;
        }
        return false;
    }

    public String getTitulo() { return titulo; }
    public void setTitulo(String titulo) { this.titulo = titulo; }

    public int getCantidadDisponible() { return cantidadDisponible; }
    public void setCantidadDisponible(int cantidadDisponible) { this.cantidadDisponible = cantidadDisponible; }
}

Fase 3 — Cargar el JSON con Gson (MaterialManager) El puente entre el archivo en disco y los objetos en memoria

Ahora que tenemos las clases Libro y Revista, ¿cómo leemos catalogo.json para crear los objetos? Usamos la librería Gson.

Paso 3.1 — El molde auxiliar DTO: CatalogoJson.java

Como catalogo.json tiene dos arreglos ("libros" y "revistas"), creamos una pequeña clase auxiliar cuyos atributos coincidan con esas claves:

📄 model/CatalogoJson.java 
package com.hachimakidev.bibliotech.model;

import java.util.List;

public class CatalogoJson {
    private List<Libro> libros;
    private List<Revista> revistas;

    public CatalogoJson() {}

    public List<Libro> getLibros() { return libros; }
    public List<Revista> getRevistas() { return revistas; }
}

Paso 3.2 — El gestor de carga: MaterialManager.java

Crea model/MaterialManager.java. Lee el JSON con Gson y añade tanto los libros como las revistas a una única lista polimórfica List<Material>:

📄 model/MaterialManager.java 
package com.hachimakidev.bibliotech.model;

import java.io.InputStream;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

import com.google.gson.Gson;

public class MaterialManager {

    private List<Material> catalogo = new ArrayList<>();

    public MaterialManager() {
        cargarDesdeJson();
    }

    private void cargarDesdeJson() {
        try {
            // 1. Abrimos el archivo en resources
            InputStream is = getClass().getResourceAsStream("/catalogo.json");
            InputStreamReader reader = new InputStreamReader(is, StandardCharsets.UTF_8);

            // 2. Gson deserializa a nuestro molde CatalogoJson
            CatalogoJson datos = new Gson().fromJson(reader, CatalogoJson.class);

            // 3. Polimorfismo: guardamos libros y revistas juntos en la lista de Material
            if (datos != null) {
                if (datos.getLibros() != null) catalogo.addAll(datos.getLibros());
                if (datos.getRevistas() != null) catalogo.addAll(datos.getRevistas());
            }

            System.out.println("Materiales cargados: " + catalogo.size());

        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    public List<Material> getCatalogo() {
        return catalogo;
    }
}

Fase 5 — El cerebro: CatalogoController y el botón Prestar Separar la lógica de negocio y conectar la acción en la pantalla

La tabla se ve impecable, pero si pulsas el botón "Prestar", aún no ocurre nada. ¿Deberíamos meter las validaciones de RUT y stock adentro de la vista? No: eso rompería el patrón MVC. Creamos un Controlador que actúe de intermediario.

Paso 5.1 — El controlador: CatalogoController.java

Crea src/main/java/com/hachimakidev/bibliotech/controller/CatalogoController.java:

Controlador · Coordinador de reglas 📄 controller/CatalogoController.java 
package com.hachimakidev.bibliotech.controller;

import java.util.List;

import com.hachimakidev.bibliotech.model.Material;
import com.hachimakidev.bibliotech.model.MaterialManager;
import com.hachimakidev.bibliotech.model.User;
import com.hachimakidev.bibliotech.model.UserManager;

public class CatalogoController {

    private MaterialManager materialManager = new MaterialManager();
    // Reutilizamos el UserManager que construimos en la Parte 1
    private UserManager userManager = new UserManager();

    public List<Material> obtenerCatalogo() {
        return materialManager.getCatalogo();
    }

    public String prestar(String rut, Material material) throws Exception {

        if (material == null) {
            throw new Exception("Debes seleccionar un material en la tabla.");
        }

        if (rut == null || rut.trim().isEmpty()) {
            throw new Exception("Escribe el RUT de quien solicita el material.");
        }

        User socio = userManager.buscarPorRut(rut.trim());
        if (socio == null) {
            throw new Exception("No existe ningún socio registrado con el RUT " + rut.trim());
        }

        if (material.getCantidadDisponible() <= 0) {
            throw new Exception("No quedan ejemplares disponibles de '" + material.getTitulo() + "'.");
        }

        // Descontamos 1 unidad del inventario
        material.prestar();

        // Devolvemos el mensaje de confirmación con el método polimórfico getDiasPrestamo()
        return socio.getNombre() + " se lleva '" + material.getTitulo() + "'.\n"
             + "Plazo de devolución: " + material.getDiasPrestamo() + " días.";
    }
}

Paso 5.2 — Conectar el controlador y el botón en CatalogoView.java

Ahora actualizamos CatalogoView.java para cambiar la instancia directa de MaterialManager por CatalogoController y programar el clic del botón:

Vista · Conectando el evento 📄 view/CatalogoView.java (Versión final completa) 
package com.hachimakidev.bibliotech.view;

import com.hachimakidev.bibliotech.controller.CatalogoController;
import com.hachimakidev.bibliotech.model.Material;

import javafx.collections.FXCollections;
import javafx.geometry.Insets;
import javafx.scene.control.Alert;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;
import javafx.scene.control.TextField;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;

public class CatalogoView {

    private CatalogoController controller = new CatalogoController();

    public VBox catalogo() {

        TableView<Material> tabla = new TableView<>();
        tabla.setPlaceholder(new Label("No hay materiales en el catálogo."));

        TableColumn<Material, String> colTipo = new TableColumn<>("Tipo");
        colTipo.setCellValueFactory(new PropertyValueFactory<>("tipo"));
        colTipo.setPrefWidth(90);

        TableColumn<Material, String> colTitulo = new TableColumn<>("Título");
        colTitulo.setCellValueFactory(new PropertyValueFactory<>("titulo"));
        colTitulo.setPrefWidth(260);

        TableColumn<Material, Integer> colDias = new TableColumn<>("Días de Préstamo");
        colDias.setCellValueFactory(new PropertyValueFactory<>("diasPrestamo"));
        colDias.setPrefWidth(130);

        TableColumn<Material, Integer> colStock = new TableColumn<>("Disponibles");
        colStock.setCellValueFactory(new PropertyValueFactory<>("cantidadDisponible"));
        colStock.setPrefWidth(110);

        tabla.getColumns().addAll(colTipo, colTitulo, colDias, colStock);
        tabla.setItems(FXCollections.observableArrayList(controller.obtenerCatalogo()));

        Label lblRut = new Label("RUT solicitante:");
        TextField txtRut = new TextField();
        txtRut.setPromptText("Ej: 12345678-9");

        Button btnPrestar = new Button("Prestar seleccionado");

        // Evento de clic: coordinado con el Controlador
        btnPrestar.setOnAction(e -> {
            Material seleccionado = tabla.getSelectionModel().getSelectedItem();

            try {
                String confirmacion = controller.prestar(txtRut.getText(), seleccionado);
                tabla.refresh(); // ¡Repinta la tabla para que el nuevo stock aparezca de inmediato!
                mostrarAlerta(Alert.AlertType.INFORMATION, "Préstamo exitoso", confirmacion);

            } catch (Exception ex) {
                mostrarAlerta(Alert.AlertType.WARNING, "No se pudo prestar", ex.getMessage());
            }
        });

        HBox panelAcciones = new HBox(10, lblRut, txtRut, btnPrestar);
        panelAcciones.setPadding(new Insets(10, 0, 0, 0));

        VBox layout = new VBox(12, tabla, panelAcciones);
        layout.setPadding(new Insets(16));
        return layout;
    }

    private void mostrarAlerta(Alert.AlertType tipo, String titulo, String mensaje) {
        Alert alert = new Alert(tipo);
        alert.setTitle(titulo);
        alert.setHeaderText(null);
        alert.setContentText(mensaje);
        alert.showAndWait();
    }
}

model/MaterialManager.java 
package com.hachimakidev.bibliotech.model;

import java.io.InputStream;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import com.google.gson.Gson;

public class MaterialManager {

    private List<Material> catalogo = new ArrayList<>();

    public MaterialManager() {
        cargarDesdeJson();
    }

    private void cargarDesdeJson() {
        try {
            InputStream is = getClass().getResourceAsStream("/catalogo.json");
            InputStreamReader reader = new InputStreamReader(is, StandardCharsets.UTF_8);

            CatalogoJson datos = new Gson().fromJson(reader, CatalogoJson.class);
            if (datos != null) {
                if (datos.getLibros() != null) catalogo.addAll(datos.getLibros());
                if (datos.getRevistas() != null) catalogo.addAll(datos.getRevistas());
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    public List<Material> getCatalogo() {
        return catalogo;
    }
}
controller/CatalogoController.java 
package com.hachimakidev.bibliotech.controller;

import java.util.List;
import com.hachimakidev.bibliotech.model.Material;
import com.hachimakidev.bibliotech.model.MaterialManager;
import com.hachimakidev.bibliotech.model.User;
import com.hachimakidev.bibliotech.model.UserManager;

public class CatalogoController {

    private MaterialManager materialManager = new MaterialManager();
    private UserManager userManager = new UserManager();

    public List<Material> obtenerCatalogo() {
        return materialManager.getCatalogo();
    }

    public String prestar(String rut, Material material) throws Exception {
        if (material == null) {
            throw new Exception("Debes seleccionar un material en la tabla.");
        }

        if (rut == null || rut.trim().isEmpty()) {
            throw new Exception("Escribe el RUT de quien solicita el material.");
        }

        User socio = userManager.buscarPorRut(rut.trim());
        if (socio == null) {
            throw new Exception("No existe ningún socio registrado con el RUT " + rut.trim());
        }

        if (material.getCantidadDisponible() <= 0) {
            throw new Exception("No quedan ejemplares disponibles de '" + material.getTitulo() + "'.");
        }

        material.prestar();

        return socio.getNombre() + " se lleva '" + material.getTitulo() + "'.\n"
             + "Plazo de devolución: " + material.getDiasPrestamo() + " días.";
    }
}

package com.hachimakidev.bibliotech.view;

import com.hachimakidev.bibliotech.controller.CatalogoController;
import com.hachimakidev.bibliotech.model.Material;

import javafx.collections.FXCollections;
import javafx.geometry.Insets;
import javafx.scene.control.Alert;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;
import javafx.scene.control.TextField;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;

public class CatalogoView {

    private CatalogoController controller = new CatalogoController();

    public VBox catalogo() {
        TableView<Material> tabla = new TableView<>();
        tabla.setPlaceholder(new Label("No hay materiales disponibles."));

        TableColumn<Material, String> colTipo = new TableColumn<>("Tipo");
        colTipo.setCellValueFactory(new PropertyValueFactory<>("tipo"));
        colTipo.setPrefWidth(90);

        TableColumn<Material, String> colTitulo = new TableColumn<>("Título");
        colTitulo.setCellValueFactory(new PropertyValueFactory<>("titulo"));
        colTitulo.setPrefWidth(260);

        TableColumn<Material, Integer> colDias = new TableColumn<>("Días de Préstamo");
        colDias.setCellValueFactory(new PropertyValueFactory<>("diasPrestamo"));
        colDias.setPrefWidth(130);

        TableColumn<Material, Integer> colStock = new TableColumn<>("Disponibles");
        colStock.setCellValueFactory(new PropertyValueFactory<>("cantidadDisponible"));
        colStock.setPrefWidth(110);

        tabla.getColumns().addAll(colTipo, colTitulo, colDias, colStock);
        tabla.setItems(FXCollections.observableArrayList(controller.obtenerCatalogo()));

        Label lblRut = new Label("RUT solicitante:");
        TextField txtRut = new TextField();
        txtRut.setPromptText("Ej: 12345678-9");

        Button btnPrestar = new Button("Prestar seleccionado");

        btnPrestar.setOnAction(e -> {
            Material seleccionado = tabla.getSelectionModel().getSelectedItem();
            try {
                String confirmacion = controller.prestar(txtRut.getText(), seleccionado);
                tabla.refresh();
                mostrarAlerta(Alert.AlertType.INFORMATION, "Préstamo exitoso", confirmacion);
            } catch (Exception ex) {
                mostrarAlerta(Alert.AlertType.WARNING, "No se pudo prestar", ex.getMessage());
            }
        });

        HBox panelAcciones = new HBox(10, lblRut, txtRut, btnPrestar);
        panelAcciones.setPadding(new Insets(10, 0, 0, 0));

        VBox layout = new VBox(12, tabla, panelAcciones);
        layout.setPadding(new Insets(16));
        return layout;
    }

    private void mostrarAlerta(Alert.AlertType tipo, String titulo, String mensaje) {
        Alert alert = new Alert(tipo);
        alert.setTitle(titulo);
        alert.setHeaderText(null);
        alert.setContentText(mensaje);
        alert.showAndWait();
    }
}
