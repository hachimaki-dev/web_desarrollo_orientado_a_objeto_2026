Estrategias para Eliminar Registros

Guía directa y concisa: lógica, métodos nativos de JavaFX y código exacto por capas.

1. Vista (View)

Detecta la interacción (fila seleccionada, clic en botón o tecla) y se la pasa al Controlador.

2. Controlador (Controller)

Valida que el objeto no sea null y le ordena al Manager ejecutar la baja.

3. Manager (Model)

Ejecuta lista.remove(objeto). Al ser ObservableList, la tabla se actualiza sola.

💡 Navegación: Usa las teclas ← y → o los botones inferiores para revisar cada estrategia.

Fundamento de Datos

0. El Secreto: ¿Por qué la TableView se refresca sola?

Si usas ObservableList, no necesitas recargar escenas ni redibujar ventanas manualmente.

Lógica a Implementar

1. Enlace en la Vista tabla.setItems(controller.obtenerLista()) conecta la vista directamente con la lista observable.
2. Mutación en el Manager Al hacer lista.remove(objeto), JavaFX dispara un evento interno de redibujo automático.
Métodos indispensables: FXCollections.observableArrayList() lista.remove(item) tabla.setItems(lista)

    public {{ ctx === 'auto' ? 'VehiculoManager' : 'InstrumentoManager' }}() {
        this.lista = FXCollections.observableArrayList();
    }

    // Método que elimina de la memoria: ¡dispara el redibujo automático!

    }
}

Estrategia 1 · Recomendada para la Evaluación

Fila Seleccionada en Tabla + Botón Exterior

El usuario pincha una fila en la tabla y presiona el botón [ Eliminar ].

Lógica Paso a Paso

1. Capturar selección Usa getSelectionModel().getSelectedItem() de la tabla.
2. Validar que no sea null Si el usuario pulsó el botón sin seleccionar fila, avisa con una alerta o ignora sin caídas.
3. Delegar al Controlador Envía el objeto obtenido al controlador.
Métodos clave: tabla.getSelectionModel().getSelectedItem() controller.eliminar...(item)

    // 2. Validación preventiva contra NullPointerException
    if (seleccionado == null) {
        Alert alerta = new Alert(Alert.AlertType.WARNING);
        alerta.setTitle("Atención");
        alerta.setHeaderText(null);
        alerta.setContentText("Debes seleccionar una fila en la tabla primero.");
        alerta.showAndWait();
        return;
    }

    // 3. Ejecución a través del flujo MVC
    controller.{{ ctx === 'auto' ? 'eliminarVehiculo' : 'eliminarInstrumento' }}(seleccionado);

Estrategia 2 · Avanzada

Botón "Eliminar" en Cada Fila (TableCell)

Una columna con un botón rojo por cada celda. No requiere seleccionar la fila previamente.

Lógica Paso a Paso

1. Columna tipo Void La columna no contiene texto, contendrá un botón.
2. CellFactory personalizada Se crea un botón en el constructor de la celda y se le asigna el evento.
3. getIndex() para la fila getTableView().getItems().get(getIndex()) obtiene el objeto de esa fila exacta.
Métodos clave: col.setCellFactory(...) getIndex() setGraphic(empty ? null : btn)

        btnFila.setStyle("-fx-background-color: #ef4444; -fx-text-fill: white; -fx-cursor: hand;");
        btnFila.setOnAction(event -> {
            // Obtener el objeto perteneciente a la celda clickeada
            {{ ctx === 'auto' ? 'Vehiculo' : 'Instrumento' }} item = getTableView().getItems().get(getIndex());

Selector Desplegable (ComboBox / ChoiceBox)

El usuario elige el registro desde un ComboBox y pulsa [ Dar de Baja ].

Estrategia 4 · Profesional de Escritorio

Menú Contextual (Clic Derecho en Fila)

Clic derecho sobre la fila abre un ContextMenu flotante con la acción de eliminar.

Lógica Paso a Paso

1. Configurar RowFactory Se define cómo se comporta cada fila (TableRow) de la tabla.
2. Crear ContextMenu Se crea el menú con un MenuItem("Eliminar").
3. Enlazar a row.emptyProperty() Evita que el menú aparezca si el usuario hace clic derecho en el espacio vacío de la tabla.
Métodos clave: tabla.setRowFactory(...) row.getItem() row.emptyProperty()
CatalogoView.java — RowFactory con ContextMenu Vista 
tabla.setRowFactory(tv -> {
    TableRow<{{ ctx === 'auto' ? 'Vehiculo' : 'Instrumento' }}> row = new TableRow<>();
    ContextMenu menu = new ContextMenu();
    MenuItem itemEliminar = new MenuItem("🗑️ Eliminar este registro");

    itemEliminar.setOnAction(e -> {
        {{ ctx === 'auto' ? 'Vehiculo' : 'Instrumento' }} item = row.getItem();
        if (item != null) {
            controller.{{ ctx === 'auto' ? 'eliminarVehiculo' : 'eliminarInstrumento' }}(item);
        }
    });

    menu.getItems().add(itemEliminar);

    // Asignar el menú únicamente si la fila contiene datos reales
    row.contextMenuProperty().bind(
        Bindings.when(row.emptyProperty()).then((ContextMenu) null).otherwise(menu)
    );

    return row;
});
Estrategia 5 · Teclado / Productividad

Atajo de Teclado (Tecla Supr / DELETE)

El usuario selecciona la fila y presiona la tecla Delete (o Backspace) para borrar.

Lógica Paso a Paso

1. Escuchar eventos de tecla Se asigna setOnKeyPressed al componente TableView.
2. Evaluar KeyCode Se compara event.getCode() == KeyCode.DELETE.
3. Tomar selección y borrar Si hay un elemento seleccionado, se delega al controlador.
Métodos clave: tabla.setOnKeyPressed(...) event.getCode() == KeyCode.DELETE
CatalogoView.java — Listener de Tecla Vista

        {{ ctx === 'auto' ? 'Vehiculo' : 'Instrumento' }} seleccionado = tabla.getSelectionModel().getSelectedItem();
        
        if (seleccionado != null) {
            controller.{{ ctx === 'auto' ? 'eliminarVehiculo' : 'eliminarInstrumento' }}(seleccionado);
        }
    }
});
Buena Práctica UX

Confirmación Previa con Alert

Evita que el usuario borre registros por error. Compatible con cualquiera de las 5 estrategias.

Lógica Paso a Paso

1. Alert CONFIRMATION Crea una ventana modal nativa con botones Aceptar y Cancelar.
2. showAndWait() Pausa la ejecución de forma síncrona esperando la respuesta del usuario.
3. Comparar con ButtonType.OK Solo procede con la baja si el usuario confirmó con Aceptar.
Métodos clave: new Alert(AlertType.CONFIRMATION) alert.showAndWait() respuesta.get() == ButtonType.OK
Snippet reutilizable con confirmación UX / Vista 
import javafx.scene.control.Alert;
import javafx.scene.control.ButtonType;
import java.util.Optional;

// Crear cuadro de confirmación
Alert confirm = new Alert(Alert.AlertType.CONFIRMATION);
confirm.setTitle("Confirmar Eliminación");
confirm.setHeaderText("¿Estás seguro de eliminar este registro?");
confirm.setContentText("Se eliminará: " + seleccionado.getMarca() + " " + seleccionado.getModelo());

// Esperar respuesta del usuario
Optional<ButtonType> respuesta = confirm.showAndWait();

if (respuesta.isPresent() && respuesta.get() == ButtonType.OK) {
    controller.{{ ctx === 'auto' ? 'eliminarVehiculo' : 'eliminarInstrumento' }}(seleccionado);
}
