Layouts y Componentes 🧩

Aprende a estructurar interfaces bonitas y ordenadas en JavaFX: layouts, componentes funcionales reutilizables y CSS estilo Spotify.

Antes de empezar

Esta guía asume que ya:

  • Tienes un proyecto Maven con JavaFX configurado (lo viste en la guía 2.1.2)
  • Sabes crear una ventana básica con Application, Stage y Scene
  • Conoces Label, Button y TextField a nivel conceptual

🎯 Propósito de esta guía

Aprender a pensar, estructurar y diseñar interfaces gráficas como un desarrollador profesional de software orientado a objetos. Dejarás atrás el mal hábito de picar código espagueti en un solo método y dominarás la metodología de bloques LEGO: descomponer una pantalla en componentes visuales modulares, organizarlos con layouts matemáticamente ordenados y darles vida con hojas de estilo CSS.

🚀 ¿Qué serás capaz de hacer al finalizar?

🧱
1. Pensamiento Visual LEGO

Descomponer cualquier boceto de interfaz en una jerarquía de cajas contenedoras anidadas antes de tocar el teclado.

📐
2. Dominio de los 3 Layouts

Dominar VBox (vertical), HBox (horizontal) y GridPane (matriz 2D) con márgenes y alineación.

🧩
3. Componentes Modulares

Aplicar responsabilidad única: cada sección visual se construye en su propio método privado reutilizable.

🎨
4. Estilizado Profesional

Separar estructura de diseño usando hojas de estilo styles.css, clases e IDs, desterrando setStyle().

¿Cómo piensa un desarrollador senior antes de abrir el editor de código? Nunca empieza escribiendo botones ni campos en start(). Primero descompone el problema en una hoja de papel siguiendo 4 fases mentales:

Decidir qué contenedor se adapta mejor: ¿VBox (apilado)? ¿HBox (fila)? ¿GridPane (tabla)?

3

Blueprint Visual · Descomposición en Bloques LEGO
PLACA BASE: VBox (Contenedor Raíz Vertical)
🟢 Bloque 1: Título ➔ Label ("Spotify Mini 🎧") crearTitulo()
🟡 Bloque 2: Formulario ➔ GridPane (Grilla 2x3 con Labels y TextFields) crearFormulario()
🟣 Bloque 3: Acciones ➔ HBox (Fila horizontal con [Agregar] [Limpiar]) crearBotones()

Fíjate en la potencia de este diseño: Cada bloque es autónomo. Si en el futuro necesitas cambiar el formulario a 5 campos, solo modificas el método crearFormulario(). El resto de la app, el título, los botones y el método start() siguen intactos. ¡Esa es la verdadera magia de la POO!

Fase 1 — El problema: todo achoclonado 🍝
1
Mira este código — ¿qué tiene de malo?

Este es un ejemplo típico de alguien que recién empieza con JavaFX. Todo está dentro de start(), sin orden ni estructura:

@Override
public void start(Stage stage) {
    Label titulo = new Label("Spotify Mini");
    titulo.setStyle("-fx-font-size: 20px; -fx-text-fill: #1db954; -fx-font-weight: bold;");

    Label lblCancion = new Label("Canción:");
    TextField txtCancion = new TextField();
    txtCancion.setPromptText("Nombre de la canción");
    Label lblArtista = new Label("Artista:");
    TextField txtArtista = new TextField();
    txtArtista.setPromptText("Nombre del artista");

    GridPane formulario = new GridPane();
    formulario.setHgap(10);
    formulario.setVgap(10);
    formulario.add(lblCancion, 0, 0);
    formulario.add(txtCancion, 1, 0);
    formulario.add(lblArtista, 0, 1);
    formulario.add(txtArtista, 3, 7);   // Columna 3, fila 7... ¿por qué?

    Button btnAgregar = new Button("Agregar");
    btnAgregar.setStyle("-fx-background-color: #1db954; -fx-text-fill: white;");
    btnAgregar.setOnAction(e -> {
        String cancion = txtCancion.getText();
        String artista = txtArtista.getText();
        if (!cancion.isEmpty() && !artista.isEmpty()) {
            System.out.println("Agregado: " + cancion + " - " + artista);
            txtCancion.clear();
            txtArtista.clear();
        }
    });

    HBox root = new HBox(10);
    root.getChildren().add(titulo);
    root.getChildren().add(formulario);
    root.getChildren().add(btnAgregar);

    Scene scene = new Scene(root, 600, 400);
    scene.getStylesheets().add(
        getClass().getResource("/styles.css").toExternalForm()
    );
    stage.setTitle("Spotify Mini");
    stage.setScene(scene);
    stage.show();
}

🔍 Problemas de este código:

  • Todo en un solo método — 40+ líneas de controles, estilos, eventos y configuración mezclados. Si necesitas cambiar algo, tienes que buscar entre toda la maraña
  • Layout incorrecto — un HBox pone todo en una fila horizontal (título, formulario y botón, todo al lado). La interfaz se ve aplastada
  • GridPane mal usado — (3, 7) es columna 3, fila 7 — el campo del artista queda lejos del label, en otra dimensión
  • Estilos inline — setStyle() mezcla el diseño con la lógica. Si quieres cambiar un color, tienes que buscar en el Java
  • Sin padding ni alignment — los elementos quedan pegados al borde de la ventana
  • Sin estructura visual — no hay jerarquía clara entre secciones de la interfaz

🤔 Reflexiona: Si alguien más tuviera que modificar este código (o tú mismo en 2 semanas), ¿sabrías rápidamente qué hace cada parte? La respuesta honesta es que cuesta. Y eso se soluciona.

Fase 2 — Los 3 layouts esenciales
2
VBox — Apilar elementos verticalmente

VBox organiza sus hijos uno debajo del otro. Es el layout más natural para una interfaz: título arriba, formulario al medio, botones abajo.

import javafx.scene.layout.VBox;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;

// 1. Crear VBox con 15px de espacio entre elementos
VBox root = new VBox(15);

// 2. Padding: espacio interior (arriba, derecha, abajo, izquierda)
root.setPadding(new Insets(20));

// 3. Alineación: centrar todo horizontalmente
root.setAlignment(Pos.TOP_CENTER);

// 4. Agregar hijos
root.getChildren().addAll(titulo, formulario, btnAgregar);

// 5. ¡Paso indispensable para ver la ventana!
Scene scene = new Scene(root, 500, 400);
stage.setTitle("Spotify Mini");
stage.setScene(scene);
stage.show(); // <-- ¡Sin esto, la ventana NUNCA se abrirá!
VBox(15) + padding 20 + alignment TOP_CENTER

Formulario
Botones
Método Qué hace Ejemplo
new VBox(spacing) Crea el VBox con espacio entre hijos new VBox(15)
setPadding(Insets) Margen interior (espacio entre el borde y el contenido) new Insets(20) o new Insets(10, 20, 10, 20)
setAlignment(Pos) Dónde se ubican los hijos dentro del VBox Pos.TOP_CENTER, Pos.CENTER
setSpacing(double) Cambia el espacio entre hijos después de crear root.setSpacing(20)

🚨 ¿Ejecutaste y no se abre ninguna ventana?

Un tropiezo muy habitual al empezar es armar el VBox con sus nodos pero olvidar incluir Scene scene = new Scene(root, 500, 400);, stage.setScene(scene); y stage.show(); al final del método start(). Sin stage.show(), JavaFX arranca en segundo plano pero jamás muestra nada en pantalla.

⚠️ ¿Te sale en la terminal: "ADVERTENCIA: Unsupported JavaFX configuration: classes were loaded from 'unnamed module'"?

¡Tranquilidad total, NO es un error fatal! Es solo un aviso informativo de JavaFX indicando que las librerías se cargaron desde el classpath clásico (sin module-info.java) al ejecutar desde Main.java en VS Code. Tu aplicación funciona sin ningún problema. Si ejecutas con mvn javafx:run en la terminal, ese aviso ni siquiera aparece.

3
HBox — Organizar en fila horizontal

HBox organiza sus hijos uno al lado del otro. Ideal para barras de botones, filas de controles o secciones horizontales.

import javafx.scene.layout.HBox;

// Barra de botones con 10px de espacio
HBox botones = new HBox(10);
botones.setAlignment(Pos.CENTER);
botones.getChildren().addAll(btnAgregar, btnLimpiar);
HBox(10) + alignment CENTER
🎵 Agregar
🧹 Limpiar

Tip: HBox y VBox comparten los mismos métodos (setPadding, setAlignment, setSpacing). La única diferencia es la dirección: horizontal vs vertical.

4
GridPane — Formularios organizados

GridPane organiza elementos en una grilla de filas y columnas. Es perfecto para formularios donde tienes etiquetas a la izquierda y campos a la derecha.

import javafx.scene.layout.GridPane;

GridPane formulario = new GridPane();
formulario.setHgap(10);    // Espacio horizontal entre columnas
formulario.setVgap(10);    // Espacio vertical entre filas

// .add(nodo, columna, fila)  ← ¡CUIDADO! Es columna primero, fila después
formulario.add(lblTitulo,    0, 0);    // Columna 0, Fila 0
formulario.add(txtTitulo,    1, 0);    // Columna 1, Fila 0
formulario.add(lblArtista,   0, 1);    // Columna 0, Fila 1
formulario.add(txtArtista,   1, 1);    // Columna 1, Fila 1
formulario.add(lblDuracion,  0, 2);    // Columna 0, Fila 2
formulario.add(txtDuracion,  1, 2);    // Columna 1, Fila 2

💡 Regla de oro: Piensa siempre en coordenadas cartesianas (X, Y). La columna es el eje X (horizontal) y la fila es el eje Y (vertical).

⚠️ Error común en GridPane

El orden de los parámetros es (nodo, columna, fila) — columna primero. Muchos escriben (nodo, fila, columna) por costumbre y todo queda desordenado. El ejemplo malo del paso 1 tenía (3, 7) que es columna 3, fila 7 — ¡totalmente fuera de lugar!

5
Combinar layouts (nesting) — La clave de las interfaces reales

Las interfaces reales nunca usan un solo layout. La magia está en anidar (combinar) layouts: un VBox principal que contiene un GridPane para el formulario y un HBox para los botones.

VBox (root — contenedor principal)
├── Label — título "Spotify Mini 🎧"
├── GridPane — formulario
│   ├── Label + TextField (título canción)
│   ├── Label + TextField (artista)
│   └── Label + TextField (duración)
├── HBox — barra de botones
│   ├── Button "Agregar"
│   └── Button "Limpiar"
└── Label — estado 
// El VBox contiene TODO, apilado verticalmente
VBox root = new VBox(15);
root.setPadding(new Insets(20));
root.setAlignment(Pos.TOP_CENTER);

// Agregar los "bloques" al VBox
root.getChildren().addAll(
    titulo,       // Label
    formulario,   // GridPane (contiene labels + textfields)
    botones,      // HBox (contiene los botones)
    lblEstado     // Label de estado
);

Scene scene = new Scene(root, 500, 400);
stage.setTitle("Spotify Mini");
stage.setScene(scene);
stage.show();

Fase 3 — Componentes funcionales: divide y conquista 🧩
6
La filosofía: cada pieza es un "componente"

En vez de meter todo en start() como una olla de espagueti 🍝, vamos a crear métodos que construyen y retornan cada pieza visual de la interfaz.

La idea es simple: cada método es un componente. Recibe lo que necesita, construye el nodo visual, y lo retorna listo para usar.

❌ Todo achoclonado

public void start(Stage stage) {
    // 80 líneas de código...
    // Labels por aquí...
    // TextFields por allá...
    // GridPane...
    // Botones...
    // Eventos...
    // CSS...
    // Scene...
    // Todo mezclado 🍝
}

✅ Componentes funcionales

public void start(Stage stage) {
    Label titulo = crearTitulo();
    GridPane form = crearFormulario();
    HBox botones = crearBotones();
    Label estado = crearEstado();

    VBox root = new VBox(15,
        titulo, form, botones, estado
    );
    // Limpio, legible, mantenible ✨
}

🧩 ¿Qué es un "componente funcional"?

Es un método que construye y retorna un nodo visual. Así como en una fábrica cada estación hace una pieza del producto, en tu código cada método construye una pieza de la interfaz. El método start() solo ensambla las piezas.

🏭 La Fábrica de Componentes: cada método entrega una pieza

🟢 crearTitulo() → Retorna Label
Pieza 1: Título
🟡 crearFormulario() → Retorna GridPane
Pieza 2: Formulario
🟣 crearBotones() → Retorna HBox
Pieza 3: Botones
🟠 crearEstado() → Retorna Label
Pieza 4: Estado
⬇️ El método start() solo hace esto: root = new VBox(15, titulo, form, botones, estado);
7
Componente: crearTitulo()

El componente más simple: un método que crea un Label, le asigna un ID para CSS, y lo retorna.

/**
 * Crea el título principal de la aplicación.
 * @return Label con el título estilizado
 */
private Label crearTitulo() {
    Label titulo = new Label("Spotify Mini 🎧");
    titulo.setId("titulo-app");
    return titulo;
}

Fíjate en el patrón: El método es private (solo lo usa esta clase), retorna un tipo de nodo JavaFX (Label), y su nombre describe exactamente qué construye.

8
Componente: crearFormulario()

El formulario necesita que los TextField sean accesibles desde otros métodos (para leer lo que el usuario escribió). Por eso los declaramos como atributos de la clase:

// Atributos de la clase — accesibles desde cualquier método
private TextField txtTitulo;
private TextField txtArtista;
private TextField txtDuracion;

/**
 * Crea el formulario con labels y campos de texto organizados en grilla.
 * @return GridPane con el formulario listo
 */
private GridPane crearFormulario() {
    // Crear los labels
    Label lblTitulo   = new Label("Título:");
    Label lblArtista  = new Label("Artista:");
    Label lblDuracion = new Label("Duración:");

    // Crear los campos de texto
    txtTitulo = new TextField();
    txtTitulo.setPromptText("Nombre de la canción");

    txtArtista = new TextField();
    txtArtista.setPromptText("Nombre del artista");

    txtDuracion = new TextField();
    txtDuracion.setPromptText("Ej: 3:45");

    // Armar la grilla
    GridPane form = new GridPane();
    form.setHgap(10);
    form.setVgap(10);

    //               columna, fila
    form.add(lblTitulo,    0, 0);
    form.add(txtTitulo,    1, 0);
    form.add(lblArtista,   0, 1);
    form.add(txtArtista,   1, 1);
    form.add(lblDuracion,  0, 2);
    form.add(txtDuracion,  1, 2);

    return form;
}

📌 ¿Por qué atributos de clase?

Los Label solo se muestran — no necesitas acceder a ellos después. Pero los TextField necesitas leerlos cuando el usuario hace clic en "Agregar". Si fueran variables locales del método, no podrías acceder a ellos desde el evento del botón.

9
Componente: crearBotones()

La barra de botones usa un HBox. Los eventos (setOnAction) también los definimos aquí, porque están directamente ligados al botón:

// Atributo de clase — el label de estado se actualiza desde los botones
private Label lblEstado;

/**
 * Crea la barra de botones con sus eventos.
 * @return HBox con los botones listos
 */
private HBox crearBotones() {
    Button btnAgregar = new Button("Agregar Canción");
    btnAgregar.setId("btn-agregar");

    // Evento: cuando hacen clic en "Agregar"
    btnAgregar.setOnAction(e -> {
        String titulo = txtTitulo.getText();
        String artista = txtArtista.getText();

        if (titulo.isEmpty() || artista.isEmpty()) {
            lblEstado.setText("⚠ Completa al menos título y artista");
            return;
        }

        // Aquí iría la lógica de agregar a la colección
        lblEstado.setText("✓ Canción agregada: " + titulo);
        limpiarCampos();
    });

    Button btnLimpiar = new Button("Limpiar");
    btnLimpiar.getStyleClass().add("btn-secundario");

    // Evento: cuando hacen clic en "Limpiar"
    btnLimpiar.setOnAction(e -> {
        limpiarCampos();
        lblEstado.setText("");
    });

    // Armar la fila de botones
    HBox barra = new HBox(10, btnAgregar, btnLimpiar);
    barra.setAlignment(Pos.CENTER);
    return barra;
}

/**
 * Limpia todos los campos del formulario.
 */
private void limpiarCampos() {
    txtTitulo.clear();
    txtArtista.clear();
    txtDuracion.clear();
}

Fíjate: limpiarCampos() también es un "componente funcional" — un método con una sola responsabilidad. Si mañana agregas más campos, solo modificas este método.

10
Componente: crearEstado()

Un label simple que muestra mensajes al usuario (confirmaciones, errores, etc.):

/**
 * Crea el label de estado para mensajes al usuario.
 * @return Label de estado
 */
private Label crearEstado() {
    lblEstado = new Label("");
    lblEstado.setId("lbl-estado");
    return lblEstado;
}
11
El ensamblaje final: start() limpio y claro

Ahora start() solo ensambla los componentes. Fíjate qué fácil se lee:

@Override
public void start(Stage stage) {
    // 1. Crear cada componente
    Label titulo       = crearTitulo();
    GridPane formulario = crearFormulario();
    HBox botones       = crearBotones();
    Label estado       = crearEstado();

    // 2. Ensamblar en el layout principal
    VBox root = new VBox(15, titulo, formulario, botones, estado);
    root.setPadding(new Insets(20));
    root.setAlignment(Pos.TOP_CENTER);

    // 3. Crear la escena y aplicar estilos
    Scene scene = new Scene(root, 500, 400);
    scene.getStylesheets().add(
        getClass().getResource("/styles.css").toExternalForm()
    );

    // 4. Configurar y mostrar la ventana
    stage.setTitle("Spotify Mini");
    stage.setScene(scene);
    stage.show();
}
Mapa de componentes:

start() → ensambla todo
├── crearTitulo() → retorna Label
├── crearFormulario() → retorna GridPane
├── crearBotones() → retorna HBox
│   └── limpiarCampos() → helper
└── crearEstado() → retorna Label
Checkpoint ✅

Si ejecutas la app ahora (sin CSS), deberías ver una ventana con el formulario organizado, los botones centrados, y el label de estado. Todo funcional pero sin estilo visual todavía.

📌 Selectores CSS en JavaFX — resumen rápido

Tipo Sintaxis CSS Cómo se asigna en Java
Por tipo .label, .button, .text-field Automático — aplica a todos los nodos de ese tipo
Por ID #titulo-app nodo.setId("titulo-app")
Por clase CSS .btn-secundario nodo.getStyleClass().add("btn-secundario")
Pseudoclase :hover, :focused, :pressed Automático — JavaFX las activa según el estado

💡 ID vs Clase CSS: Usa setId() cuando el nodo es único (hay un solo título, un solo botón principal). Usa getStyleClass().add() cuando hay varios nodos con el mismo estilo (varios botones secundarios).

13
Vincular el CSS a la escena

En tu método start(), agrega esta línea después de crear la Scene:

// Cargar el archivo CSS desde resources/
scene.getStylesheets().add(
    getClass().getResource("/styles.css").toExternalForm()
);

⚠️ Error muy común

Si te sale NullPointerException en esta línea, significa que JavaFX no encuentra el archivo. Verifica que:

  • El archivo se llame exactamente styles.css (con la "s" al final)
  • Esté en src/main/resources/ (NO dentro de la carpeta Java)
  • La ruta empiece con / (barra diagonal)

package com.spotify.mini;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;
import javafx.scene.layout.GridPane;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class SpotifyMiniApp extends Application {

    // --- Atributos de clase: nodos que se usan en varios métodos ---
    private TextField txtTitulo;
    private TextField txtArtista;
    private TextField txtDuracion;
    private Label lblEstado;

    @Override
    public void start(Stage stage) {
        // 1. Crear cada componente
        Label titulo        = crearTitulo();
        GridPane formulario = crearFormulario();
        HBox botones        = crearBotones();
        Label estado        = crearEstado();

        // 2. Ensamblar en el layout principal
        VBox root = new VBox(15, titulo, formulario, botones, estado);
        root.setPadding(new Insets(20));
        root.setAlignment(Pos.TOP_CENTER);

        // 3. Crear la escena y aplicar estilos
        Scene scene = new Scene(root, 500, 400);
        scene.getStylesheets().add(
            getClass().getResource("/styles.css").toExternalForm()
        );

        // 4. Configurar y mostrar la ventana
        stage.setTitle("Spotify Mini");
        stage.setScene(scene);
        stage.show();
    }

    // =============================================
    // COMPONENTES — cada método construye una pieza
    // =============================================

    private Label crearTitulo() {
        Label titulo = new Label("Spotify Mini 🎧");
        titulo.setId("titulo-app");
        return titulo;
    }

    private GridPane crearFormulario() {
        Label lblTitulo   = new Label("Título:");
        Label lblArtista  = new Label("Artista:");
        Label lblDuracion = new Label("Duración:");

        txtTitulo = new TextField();
        txtTitulo.setPromptText("Nombre de la canción");

        txtArtista = new TextField();
        txtArtista.setPromptText("Nombre del artista");

        txtDuracion = new TextField();
        txtDuracion.setPromptText("Ej: 3:45");

        GridPane form = new GridPane();
        form.setHgap(10);
        form.setVgap(10);

        form.add(lblTitulo,    0, 0);
        form.add(txtTitulo,    1, 0);
        form.add(lblArtista,   0, 1);
        form.add(txtArtista,   1, 1);
        form.add(lblDuracion,  0, 2);
        form.add(txtDuracion,  1, 2);

        return form;
    }

    private HBox crearBotones() {
        Button btnAgregar = new Button("Agregar Canción");
        btnAgregar.setId("btn-agregar");

        btnAgregar.setOnAction(e -> {
            String titulo = txtTitulo.getText();
            String artista = txtArtista.getText();

            if (titulo.isEmpty() || artista.isEmpty()) {
                lblEstado.setText("⚠ Completa al menos título y artista");
                return;
            }

            lblEstado.setText("✓ Canción agregada: " + titulo);
            limpiarCampos();
        });

        Button btnLimpiar = new Button("Limpiar");
        btnLimpiar.getStyleClass().add("btn-secundario");

        btnLimpiar.setOnAction(e -> {
            limpiarCampos();
            lblEstado.setText("");
        });

        HBox barra = new HBox(10, btnAgregar, btnLimpiar);
        barra.setAlignment(Pos.CENTER);
        return barra;
    }

    private Label crearEstado() {
        lblEstado = new Label("");
        lblEstado.setId("lbl-estado");
        return lblEstado;
    }

    // =============================================
    // HELPERS — métodos de apoyo
    // =============================================

    private void limpiarCampos() {
        txtTitulo.clear();
        txtArtista.clear();
        txtDuracion.clear();
    }

    public static void main(String[] args) {
        launch(args);
    }
}

Las 5 reglas para layouts bonitos y mantenibles
1. Elige el layout raíz correcto

El 90% de las veces tu raíz es un VBox. Apila secciones verticalmente y agrega los demás layouts como hijos.

2. Siempre agrega padding

root.setPadding(new Insets(20)) — sin esto, todo queda pegado al borde de la ventana. Es lo primero que mejora cualquier interfaz.

3. Siempre agrega spacing

new VBox(15) o setSpacing(15) — sin espacio entre elementos, todo se ve apretado y confuso.

4. Usa alineación

setAlignment(Pos.CENTER) — centra los elementos para que no queden todos pegados a la izquierda. Hace una diferencia enorme.

5. Un método, una responsabilidad

Cada componente visual en su propio método. start() solo ensambla. Así tu código se lee como un índice.

Cheatsheet: ¿Cuándo usar cada layout?
Layout Dirección Úsalo para... Ejemplo típico
VBox ↓ Vertical Contenedor principal, secciones apiladas Título + formulario + botones + lista
HBox → Horizontal Filas de botones, controles lado a lado Barra de botones, campo con botón al lado
GridPane ⊞ Grilla Formularios con labels y campos alineados Label: [campo] en varias filas

🧩 Patrón más común:

VBox como raíz → contiene un GridPane para el formulario + un HBox para los botones. Este combo resuelve el 80% de las interfaces de formulario.
