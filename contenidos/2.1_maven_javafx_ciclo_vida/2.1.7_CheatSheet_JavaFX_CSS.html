Guía Completa: CSS Tradicional vs JavaFX CSS

Tabla comparativa técnica, directa y exhaustiva de todas las propiedades de estilo. Conoce cómo se escribe cada propiedad en CSS web tradicional, para qué sirve exactamente y cómo se implementa en JavaFX con el motor CSS de OpenJFX.

📌 3 Reglas de Oro de JavaFX CSS

1. El prefijo obligatorio -fx-: JavaFX utiliza su propia implementación de CSS basada en la especificación W3C CSS 2.1 con agregados de CSS 3. Todas las propiedades nativas de nodos JavaFX deben comenzar con -fx-.

2. color no existe: En HTML/CSS tradicional el color del texto es color. En JavaFX es -fx-text-fill para textos y etiquetas, y -fx-fill para figuras geométricas.

3. Separación de Fondo y Borde: En CSS web, border-radius redondea tanto el borde como el fondo. En JavaFX están separados: debes definir -fx-background-radius para el relleno y -fx-border-radius para la línea.

4. Selectores y clases raíz: En vez de body o :root, el contenedor principal de la escena en JavaFX responde al selector de clase .root.

🚀 Cómo aplicar estilos en un proyecto JavaFX

Método 1: Archivo externo .css (Recomendado)

Se ubica en src/main/resources/styles.css y se vincula a la escena en Java:

// En el método start(Stage stage):
Scene scene = new Scene(root, 800, 600);
scene.getStylesheets().add(
    getClass().getResource("/styles.css").toExternalForm()
);
stage.setScene(scene);
Método 2: Inline con setStyle()

Directo sobre el nodo (útil para pruebas puntuales o valores dinámicos):

Button btn = new Button("Confirmar");
btn.setStyle(
    "-fx-background-color: #1db954; " +
    "-fx-text-fill: white; " +
    "-fx-font-weight: bold; " +
    "-fx-background-radius: 8;"
);

1. Texto, Tipografía y Etiquetas (Labeled / Text)

Aplica a Label, Button, CheckBox, RadioButton, TextField y cualquier control que renderice caracteres.

CSS Tradicional (Web) ¿Para qué sirve? JavaFX CSS Sintaxis y Ejemplo
color: #ffffff; DIFERENCIA CRÍTICA Color del texto
Define el color de los glifos de la fuente. En JavaFX 'color' no existe.
 -fx-text-fill -fx-text-fill: #1db954;
Hex, rgb, rgba o nombres web.
font-family: Arial; Familia tipográfica
Nombre de la fuente instalada en el sistema operativo o cargada con Font.loadFont().
 -fx-font-family -fx-font-family: "Segoe UI", sans-serif;
font-size: 16px; Tamaño de fuente
Altura de los caracteres. Admite unidades en px o pt.
 -fx-font-size -fx-font-size: 14px;
o -fx-font-size: 12pt;
font-weight: bold; Grosor de la letra
Peso visual del trazo tipográfico.
 -fx-font-weight -fx-font-weight: bold;
Valores: normal, bold, bolder, 100..900
font-style: italic; Estilo cursiva
Declara si el texto se dibuja en itálica u oblicua.
 -fx-font-style -fx-font-style: italic;
Valores: normal, italic, oblique
text-align: center; Alineación del contenido
Posiciona el texto y sus gráficos respecto a los límites de la caja.
 -fx-alignment -fx-alignment: center;
center, center-left, top-right, etc.
text-decoration: underline; Subrayado
Línea continua debajo del texto. En JavaFX es un valor booleano.
 -fx-underline -fx-underline: true;
Booleano: true o false
text-decoration: line-through; Texto tachado
Dibuja una línea horizontal por el medio del texto.
 -fx-strikethrough -fx-strikethrough: true;
Booleano: true o false
white-space: normal; Ajuste automático de línea
Permite que el texto salte a la siguiente línea si no cabe en el ancho del Label.
 -fx-wrap-text -fx-wrap-text: true;
Por defecto los Labels cortan el texto.
text-overflow: ellipsis; Carácter de recorte
Cadena mostrada cuando el texto excede los límites disponibles.
 -fx-ellipsis-string -fx-ellipsis-string: "...";
gap: 8px; (icono-texto) Separación texto e icono
Distancia en píxeles entre la imagen gráfica y la etiqueta de texto en un Botón/Label.
 -fx-graphic-text-gap -fx-graphic-text-gap: 8;
flex-direction / layout Posición del gráfico relativo al texto
Dónde se ubica la imagen adjunta con setGraphic() respecto al texto.
 -fx-content-display -fx-content-display: left;
top, right, bottom, left, graphic-only, text-only

2. Fondos y Rellenos (Region / Panes / Controls)

Aplica a Region, contenedores (VBox, HBox, BorderPane, GridPane) y componentes interactivos.

CSS Tradicional (Web) ¿Para qué sirve? JavaFX CSS Sintaxis y Ejemplo
background-color: #282828; Color de fondo sólido
Pinta la capa base de relleno del componente. Permite múltiples capas separadas por coma.
 -fx-background-color -fx-background-color: #282828;
o transparent
border-radius: 8px; IMPORTANTE Radio de esquinas del fondo
Curvatura de las cuatro esquinas del fondo. En web se usa border-radius; en JavaFX se llama background-radius.
 -fx-background-radius -fx-background-radius: 8;
o 8 8 0 0; (top right bottom left)
linear-gradient(...) Fondo con gradiente lineal
Transición suave de colores en una dirección determinada.
 -fx-background-color: linear-gradient(...) linear-gradient(to bottom, #1db954, #191414);
O sintaxis JavaFX: linear-gradient(from 0% 0% to 0% 100%, #333 0%, #111 100%)
radial-gradient(...) Fondo con gradiente radial
Transición circular expansiva de colores desde un punto focal.
 -fx-background-color: radial-gradient(...) radial-gradient(center 50% 50%, radius 60%, #fff, #333);
box-sizing / padding-box Márgenes internos del fondo (Insets)
Determina qué tan retraído se dibuja el fondo respecto al borde exterior.
 -fx-background-insets -fx-background-insets: 0;
Permite capas: 0, 1 1 1 1, 2 para biseles.
background-image: url(...); Imagen de fondo
Carga un archivo gráfico para proyectarlo como fondo.
 -fx-background-image -fx-background-image: url("bg.png");
background-repeat: no-repeat; Repetición de imagen de fondo
Define si la imagen se repite en mosaico X, Y o ambos.
 -fx-background-repeat -fx-background-repeat: no-repeat;
Valores: repeat, repeat-x, repeat-y, no-repeat, space, round, stretch
background-position: center; Posición de imagen de fondo
Alinea la imagen dentro de la región del nodo.
 -fx-background-position -fx-background-position: center center;
left, right, center, top, bottom, o %
background-size: cover; Tamaño de escala de la imagen
Ajuste de dimensiones: si escala proporcionalmente, estira o encaja.
 -fx-background-size -fx-background-size: cover;
Valores: auto, cover, contain, 100% 100%

3. Bordes y Contornos (Borders)

Permite dibujar trazos continuos, punteados o con esquinas redondeadas alrededor de cualquier nodo tipo Region.

CSS Tradicional (Web) ¿Para qué sirve? JavaFX CSS Sintaxis y Ejemplo
border-color: #333333; Color del contorno
Color de las líneas perimetrales. Puede recibir de 1 a 4 colores independientes.
 -fx-border-color -fx-border-color: #333333;
o #1db954 #333 #333 #333;
border-width: 2px; Grosor del borde
Ancho de la línea en píxeles.
 -fx-border-width -fx-border-width: 2;
o 2px; (top right bottom left)
border-style: solid; Estilo de línea del borde
Determina si el trazo es sólido, punteado o discontinuo.
 -fx-border-style -fx-border-style: solid;
Valores: solid, dashed, dotted, none
border-radius: 8px; Radio de esquinas del borde
Curvatura de las líneas de borde. Debe coincidir con -fx-background-radius para un acabado armónico.
 -fx-border-radius -fx-border-radius: 8;
o 8 8 0 0;
outline-offset / insets Márgenes de desplazamiento del borde
Distancia entre el límite exterior del nodo y el trazo del borde.
 -fx-border-insets -fx-border-insets: 0;
border-image-source: url(...); Imagen como borde
Utiliza una imagen dividida en 9 secciones (9-slice) para marcos personalizados.
 -fx-border-image-source -fx-border-image-source: url("frame.png");
border-image-slice: 10; Corte de imagen de borde
Puntos de división internos para esquinas y bordes del 9-slice.
 -fx-border-image-slice -fx-border-image-slice: 10 fill;

Distancia entre el borde de la caja y sus elementos hijos internos.

Distancia fija entre elementos contiguos dentro de un VBox o HBox.

Espacio entre columnas en contenedores matriciales (GridPane, FlowPane).

Espacio entre filas en contenedores matriciales (GridPane, FlowPane).
 -fx-vgap -fx-vgap: 10;

Tamaño horizontal sugerido que el gestor de layout intentará otorgar al nodo.
 -fx-pref-width -fx-pref-width: 250;

Tamaño vertical sugerido que el gestor de layout intentará otorgar al nodo.
 -fx-pref-height -fx-pref-height: 40;

Límites por debajo de los cuales el layout no comprimirá el elemento.

6. Efectos Visuales, Sombras, Filtros y Cursor

Propiedades heredadas de la clase base Node aplicables a cualquier elemento visual de la interfaz.

CSS Tradicional (Web) ¿Para qué sirve? JavaFX CSS Sintaxis y Ejemplo
cursor: pointer; Puntero del mouse interactivo
Cambia la flecha por la mano de enlace al posarse sobre botones. En JavaFX es 'hand', no 'pointer'.
 -fx-cursor: hand; -fx-cursor: hand;
Valores: default, hand, text, crosshair, wait, move
opacity: 0.8; Transparencia del nodo completo
Nivel de opacidad entre 0.0 (totalmente transparente) y 1.0 (opaco).
 -fx-opacity -fx-opacity: 0.8;
box-shadow: 0 4px 8px #000; Sombra proyectada exterior
Genera una sombra volumétrica detrás del nodo.
 -fx-effect: dropshadow(...) dropshadow(three-pass-box, rgba(0,0,0,0.4), 10, 0, 0, 4);
Algoritmo, color, radio, spread, offsetX, offsetY
box-shadow: inset 0 0 8px #000; Sombra interna hundida
Proyecta la sombra hacia el interior de la superficie del botón o caja.
 -fx-effect: innershadow(...) innershadow(gaussian, rgba(0,0,0,0.5), 8, 0, 0, 0);
filter: blur(4px); Desenfoque gaussiano
Aplica un filtro de desenfoque al elemento.
 -fx-effect: gaussian-blur(...) -fx-effect: gaussian-blur(4);
transform: scale(1.1); Escalado de tamaño
Aumenta o reduce el tamaño visual del nodo sin recalcular el layout de sus vecinos.
 -fx-scale-x / -fx-scale-y -fx-scale-x: 1.05; -fx-scale-y: 1.05;
transform: rotate(45deg); Rotación angular
Gira el elemento en grados sexagesimales alrededor de su centro.
 -fx-rotate -fx-rotate: 45;
En grados directos (sin 'deg').
transform: translate(10px, 5px); Desplazamiento posicional
Mueve el nodo en coordenadas X o Y respecto a su posición de layout.
 -fx-translate-x / -fx-translate-y -fx-translate-x: 10; -fx-translate-y: 5;

7. Pseudo-clases y Estados de Interacción

Define reglas dinámicas que se activan según el estado del cursor, teclado o selección del componente.

CSS Tradicional (Web) ¿Para qué sirve? JavaFX CSS Ejemplo Práctico en JavaFX
:hover Cursor encima
Se activa mientras el mouse sobrevuela el control. Es idéntico en ambos entornos.
 :hover 
.button:hover {
    -fx-background-color: #1ed760;
}
:active Clic presionado
Se activa durante el instante en que el usuario mantiene apretado el botón del mouse.
 :pressed o :armed 
.button:pressed {
    -fx-background-color: #169c46;
}
:focus OJO AL NOMBRE Foco activo
Cuando el elemento tiene el foco del teclado o cursor activo. En JavaFX lleva 'd' al final (:focused).
 :focused 
.text-field:focused {
    -fx-border-color: #1db954;
    -fx-border-width: 2;
}
:disabled Elemento inhabilitado
Aplica cuando node.setDisable(true) está activo en Java.
 :disabled 
.button:disabled {
    -fx-opacity: 0.4;
    -fx-cursor: default;
}
:checked Casilla o botón activado
Para CheckBox, RadioButton, ToggleButton o pestañas Tab seleccionadas.
 :selected 
.check-box:selected > .box {
    -fx-background-color: #1db954;
}
body / html Contenedor raíz de toda la ventana
La raíz de la escena donde se declaran variables o el fondo general de la aplicación.
 .root 
.root {
    -fx-background-color: #121212;
    -fx-font-family: "Segoe UI";
}

8. Funciones Exclusivas de JavaFX CSS

JavaFX incluye funciones matemáticas de color avanzadas en su motor CSS para crear temas adaptativos automáticamente.

derive(color, porcentaje)

Aclara u oscurece un color relativo a su tono base. Porcentajes positivos aclaran; negativos oscurecen.

/* Base: verde Spotify */
.button {
    -fx-background-color: #1db954;
}
/* Al pasar mouse: 20% más claro sin inventar otro hex */
.button:hover {
    -fx-background-color: derive(#1db954, 20%);
}
/* Al hacer clic: 15% más oscuro */
.button:pressed {
    -fx-background-color: derive(#1db954, -15%);
}

ladder(color, stops...)

Selecciona automáticamente un color contrastante según la luminosidad del fondo. Es el truco que usa el tema oficial Modena para cambiar texto entre blanco y negro.

/* Si el fondo es oscuro usa blanco; si es claro usa negro */
.smart-label {
    -fx-background-color: #333333;
    -fx-text-fill: ladder(
        -fx-background-color,
        white 49%,
        black 50%
    );
}

Revisa cómo conviven todas estas propiedades en una interfaz moderna real de JavaFX:

/* 1. Raíz de la aplicación: fondo oscuro y fuente global */
.root {
    -fx-background-color: #121212;
    -fx-font-family: "Segoe UI", Arial, sans-serif;
    -fx-font-size: 14px;
}

/* 2. Títulos y etiquetas */
.title-label {
    -fx-font-size: 24px;
    -fx-font-weight: bold;
    -fx-text-fill: #1db954;
}

.subtitle-label {
    -fx-text-fill: #b3b3b3;
}

/* 3. Inputs de formulario con placeholder */
.text-field {
    -fx-background-color: #282828;
    -fx-text-fill: #ffffff;
    -fx-prompt-text-fill: #777777;
    -fx-border-color: #3e3e3e;
    -fx-border-radius: 6;
    -fx-background-radius: 6;
    -fx-padding: 8 12;
}

.text-field:focused {
    -fx-border-color: #1db954;
    -fx-border-width: 2;
}

/* 4. Botón interactivo con hover y pressed */
.btn-primary {
    -fx-background-color: #1db954;
    -fx-text-fill: #ffffff;
    -fx-font-weight: bold;
    -fx-background-radius: 20;
    -fx-padding: 10 24;
    -fx-cursor: hand;
    -fx-effect: dropshadow(three-pass-box, rgba(0,0,0,0.3), 8, 0, 0, 2);
}

.btn-primary:hover {
    -fx-background-color: derive(#1db954, 15%);
}

.btn-primary:pressed {
    -fx-background-color: derive(#1db954, -15%);
}

/* 5. Área de texto y listas con fondo interior oscuro */
.text-area {
    -fx-control-inner-background: #1e1e1e;
    -fx-text-fill: #e0e0e0;
    -fx-border-color: #3e3e3e;
    -fx-border-radius: 8;
    -fx-background-radius: 8;
    -fx-font-family: "JetBrains Mono", Consolas, monospace;
}
