Spotify Mini 🎧

Guía paso a paso para construir tu primera aplicación JavaFX con Maven: formulario, colecciones, CSS y persistencia en archivo.

Requisitos previos

Antes de comenzar, asegúrate de tener:

  • VS Code instalado con el Java Extension Pack
  • JDK 21 (o superior) instalado y configurado
  • Maven instalado (el Java Extension Pack lo incluye)
Fase 1 — Crear el proyecto Maven
1
Crea el proyecto Maven en VS Code

Abre VS Code y sigue estos pasos:

  1. Presiona Ctrl+Shift+P para abrir la paleta de comandos
  2. Escribe "Java: Create Java Project" y selecciónalo
  3. Elige "Maven" como tipo de proyecto
  4. Selecciona maven-archetype-quickstart
  5. Escribe com.spotify.mini como groupId
  6. Escribe spotify-mini como artifactId
  7. Confirma la versión 1.0-SNAPSHOT
  8. Elige una carpeta donde guardar el proyecto

VS Code creará una estructura de carpetas como esta:

spotify-mini/
├── pom.xml
└── src/
    └── main/
        ├── java/
        │   └── com/spotify/mini/
        │       └── App.java (lo reemplazaremos)
        └── resources/ (si no existe, créala)

Si la carpeta resources no existe, créala manualmente: clic derecho en src/main/ → "New Folder" → escribe resources.

2
Configura el pom.xml con JavaFX

Abre el archivo pom.xml y reemplaza todo su contenido con el siguiente código. No necesitas memorizar esto — solo cópialo:

<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.spotify.mini</groupId>
    <artifactId>spotify-mini</artifactId>
    <version>1.0</version>

    <properties>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.source>21</maven.compiler.source>
        <maven.compiler.target>21</maven.compiler.target>
        <javafx.version>21.0.2</javafx.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.openjfx</groupId>
            <artifactId>javafx-controls</artifactId>
            <version>${javafx.version}</version>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.openjfx</groupId>
                <artifactId>javafx-maven-plugin</artifactId>
                <version>0.0.8</version>
                <configuration>
                    <mainClass>com.spotify.mini.SpotifyMiniApp</mainClass>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>

¿Qué hace este archivo? Le dice a Maven: "mi proyecto se llama spotify-mini, necesita JavaFX versión 21.0.2, y la clase principal es SpotifyMiniApp". Maven se encarga del resto.

Después de guardar, VS Code puede mostrar una notificación pidiendo recargar. Acepta. Maven descargará las dependencias automáticamente (puede tomar unos segundos la primera vez).

3
Crea la clase principal SpotifyMiniApp

Si existe un archivo App.java, renómbralo o elimínalo. Crea un nuevo archivo en src/main/java/com/spotify/mini/ llamado SpotifyMiniApp.java:

package com.spotify.mini;

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class SpotifyMiniApp extends Application {

    @Override
    public void start(Stage stage) {
        Label titulo = new Label("Spotify Mini 🎧");
        VBox root = new VBox(titulo);
        Scene scene = new Scene(root, 600, 450);

        stage.setTitle("Spotify Mini");
        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}

A continuación, crea también un archivo Main.java en la misma carpeta (src/main/java/com/spotify/mini/). Esta es una clase lanzadora que permite ejecutar la aplicación directamente en VS Code con el botón Play o F5 sin errores:

package com.spotify.mini;

public class Main {
    public static void main(String[] args) {
        SpotifyMiniApp.main(args);
    }
}
Checkpoint — Cómo ejecutar la aplicación

Tienes dos formas de ejecutar tu proyecto:

  1. Forma directa (VS Code): Abre Main.java y haz clic derecho → "Run Java" (o presiona F5).
  2. Forma Maven (Terminal): Abre la terminal integrada de VS Code (Ctrl + ñ) y ejecuta: 
    mvn javafx:run

Debería abrirse una ventana con el texto "Spotify Mini 🎧".

⚠️ ¿Te aparece el error "faltan los componentes de JavaFX runtime"?

Si ejecutas directamente SpotifyMiniApp.java con "Run Java", Java 21 bloquea la ejecución porque JavaFX no está en el JDK base. Solución: Ejecuta siempre desde Main.java con clic derecho → "Run Java", o ejecuta mvn javafx:run en la terminal.

Fase 2 — Construir la interfaz
4
Crea la clase Cancion

Antes de armar la interfaz, necesitas la clase que representa los datos. Crea Cancion.java en el mismo paquete:

package com.spotify.mini;

public class Cancion {
    private String titulo;
    private String artista;
    private String duracion;

    public Cancion(String titulo, String artista, String duracion) {
        this.titulo = titulo;
        this.artista = artista;
        this.duracion = duracion;
    }

    // Getters
    public String getTitulo() { return titulo; }
    public String getArtista() { return artista; }
    public String getDuracion() { return duracion; }

    @Override
    public String toString() {
        return titulo + " — " + artista + " (" + duracion + ")";
    }
}

Esto ya lo sabes hacer. Es la misma estructura de clases con atributos, constructor, getters y toString() que usaste en las unidades anteriores.

5
Agrega los controles del formulario

Vuelve a SpotifyMiniApp.java. Reemplaza el contenido del método start() con los controles del formulario:

@Override
public void start(Stage stage) {
    // --- Título de la app ---
    Label lblTitulo = new Label("Spotify Mini 🎧");
    lblTitulo.setId("titulo-app");

    // --- Formulario con GridPane ---
    Label lblCancion = new Label("Título:");
    TextField txtTitulo = new TextField();
    txtTitulo.setPromptText("Nombre de la canción");

    Label lblArtista = new Label("Artista:");
    TextField txtArtista = new TextField();
    txtArtista.setPromptText("Nombre del artista");

    Label lblDuracion = new Label("Duración:");
    TextField txtDuracion = new TextField();
    txtDuracion.setPromptText("Ej: 3:45");

    GridPane formulario = new GridPane();
    formulario.setHgap(10);
    formulario.setVgap(10);
    formulario.add(lblCancion,  0, 0);
    formulario.add(txtTitulo,   1, 0);
    formulario.add(lblArtista,  0, 1);
    formulario.add(txtArtista,  1, 1);
    formulario.add(lblDuracion, 0, 2);
    formulario.add(txtDuracion, 1, 2);

    // --- Botones ---
    Button btnAgregar = new Button("Agregar Canción");
    btnAgregar.setId("btn-agregar");
    Button btnLimpiar = new Button("Limpiar");

    HBox botones = new HBox(10, btnAgregar, btnLimpiar);

    // --- Área de lista ---
    TextArea areaLista = new TextArea();
    areaLista.setEditable(false);
    areaLista.setPromptText("Las canciones aparecerán aquí...");
    areaLista.setPrefRowCount(8);

    // --- Label de estado ---
    Label lblEstado = new Label("");
    lblEstado.setId("lbl-estado");

    // --- Layout principal ---
    VBox root = new VBox(15, lblTitulo, formulario, botones, areaLista, lblEstado);
    root.setPadding(new Insets(20));

    // --- Escena ---
    Scene scene = new Scene(root, 600, 500);
    stage.setTitle("Spotify Mini");
    stage.setScene(scene);
    stage.show();
}

Fase 3 — Conectar la lógica
6
Declara la colección como atributo de la clase

La lista de canciones debe existir a nivel de la clase (no dentro del método start), porque la necesitarás en init() y stop() también:

import java.util.ArrayList;

public class SpotifyMiniApp extends Application {

    // Atributo de la clase — disponible en init(), start() y stop()
    private ArrayList<Cancion> canciones = new ArrayList<>();

    @Override
    public void start(Stage stage) {
        // ... todo lo del paso anterior
    }
}

¿Por qué atributo y no variable local? Porque necesitas acceder a la lista desde varios métodos: start() (para la interfaz), init() (para cargar) y stop() (para guardar).

7
Programa el botón "Agregar Canción"

Dentro del método start(), después de crear los botones y antes del layout principal, agrega la lógica del botón:

// Evento: Agregar canción
btnAgregar.setOnAction(e -> {
    String titulo = txtTitulo.getText().trim();
    String artista = txtArtista.getText().trim();
    String duracion = txtDuracion.getText().trim();

    // Validar que no estén vacíos
    if (titulo.isEmpty() || artista.isEmpty()) {
        lblEstado.setText("Completa al menos el título y artista.");
        return;
    }

    // Crear canción y agregar a la lista
    Cancion nueva = new Cancion(titulo, artista, duracion);
    canciones.add(nueva);

    // Actualizar la vista
    actualizarLista(areaLista);

    // Limpiar campos
    txtTitulo.clear();
    txtArtista.clear();
    txtDuracion.clear();
    lblEstado.setText("Canción agregada: " + titulo);
});

// Evento: Limpiar campos
btnLimpiar.setOnAction(e -> {
    txtTitulo.clear();
    txtArtista.clear();
    txtDuracion.clear();
    lblEstado.setText("");
});
8
Crea el método actualizarLista()

Este método recorre la colección y muestra todas las canciones en el TextArea. Agrégalo en la clase (fuera de start):

private void actualizarLista(TextArea areaLista) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < canciones.size(); i++) {
        sb.append((i + 1) + ". " + canciones.get(i).toString() + "\n");
    }
    if (canciones.isEmpty()) {
        areaLista.setText("");
        areaLista.setPromptText("Las canciones aparecerán aquí...");
    } else {
        areaLista.setText(sb.toString());
    }
}

Fase 5 — Persistencia en archivo .txt
11
Crea el método guardarCanciones()

Agrega este método a la clase SpotifyMiniApp. Guarda cada canción en una línea del archivo, con los campos separados por |:

import java.io.*;

private void guardarCanciones() {
    try (BufferedWriter writer = new BufferedWriter(new FileWriter("canciones.txt"))) {
        for (Cancion c : canciones) {
            writer.write(c.getTitulo() + "|" + c.getArtista() + "|" + c.getDuracion());
            writer.newLine();
        }
        System.out.println("Canciones guardadas: " + canciones.size());
    } catch (IOException e) {
        System.out.println("Error al guardar: " + e.getMessage());
    }
}

¿Por qué separar con |?

Porque un título o artista puede contener comas o espacios. El carácter | es poco común en nombres de canciones, así que es un buen separador. El archivo se verá así:

Blinding Lights|The Weeknd|3:20
Bohemian Rhapsody|Queen|5:55
Bad Guy|Billie Eilish|3:14
12
Crea el método cargarCanciones()

Este método lee el archivo línea por línea, separa los campos por |, y reconstruye los objetos Cancion:

private void cargarCanciones() {
    File archivo = new File("canciones.txt");
    if (!archivo.exists()) {
        System.out.println("No hay archivo previo. Se inicia vacío.");
        return;
    }

    try (BufferedReader reader = new BufferedReader(new FileReader(archivo))) {
        String linea;
        while ((linea = reader.readLine()) != null) {
            String[] partes = linea.split("\\|");
            if (partes.length == 3) {
                canciones.add(new Cancion(partes[0], partes[1], partes[2]));
            }
        }
        System.out.println("Canciones cargadas: " + canciones.size());
    } catch (IOException e) {
        System.out.println("Error al cargar: " + e.getMessage());
    }
}

¿Por qué \\| y no solo |?

El método split() usa expresiones regulares. En regex, | significa "o". Para que lo interprete como el carácter literal |, necesitas escaparlo con \\.

13
Conecta la persistencia al ciclo de vida

Ahora sobreescribe los métodos init() y stop() para cargar y guardar automáticamente:

@Override
public void init() {
    canciones = new ArrayList<>();
    cargarCanciones();   // Cargar desde archivo al iniciar
}

@Override
public void stop() {
    guardarCanciones();  // Guardar en archivo al cerrar
}

Y en el método start(), después de vincular el CSS, agrega una línea para mostrar las canciones que ya venían del archivo:

// Mostrar canciones cargadas del archivo (si hay)
actualizarLista(areaLista);

Construiste una aplicación JavaFX con Maven desde cero: formulario con controles, colecciones, CSS externo tipo Spotify, y persistencia en archivo de texto.

Lo que aprendiste:

• Crear y configurar un proyecto Maven con JavaFX
• Usar controles: Label, TextField, Button, TextArea

• Aplicar CSS externo con selectores y pseudoclases

• Usar el ciclo de vida: init(), start(), stop()
