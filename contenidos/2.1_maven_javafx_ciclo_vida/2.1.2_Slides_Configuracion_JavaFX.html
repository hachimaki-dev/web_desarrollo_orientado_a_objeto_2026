Unidad 2.1 · Estructura JavaFX

Estructura y Jerarquía
de JavaFX

Antes de escribir código, entiende cómo se arma una interfaz gráfica en JavaFX: qué piezas existen, qué hace cada una y cómo encajan entre sí.

🛸
Puente

El cambio mental: de consola a ventana

Hasta ahora tu programa era una secuencia lineal: el código se ejecuta línea por línea, el usuario ingresa datos por teclado, y el programa responde por pantalla.

Con JavaFX, tu programa arma una interfaz y espera. El usuario interactúa con botones, campos de texto y otros elementos, y el programa reacciona a esas acciones.

Consola (antes)

El programa controla el flujo

Scanner lee, println escribe

Todo es texto, línea por línea

Secuencial: paso 1 → paso 2 → paso 3

JavaFX (ahora)

El usuario controla el flujo

Hace clic, escribe, selecciona

La interfaz es visual: ventana con controles

Reactivo: "cuando pase X, haz Y"

Tu lógica (clases, ArrayList, constructores) no cambia. Solo cambia cómo se presenta al usuario. Por eso necesitas entender primero la estructura de una interfaz JavaFX antes de escribir código.

Concepto clave

Analogía: una app JavaFX es como un teatro

Para entender la estructura de JavaFX, piensa en un teatro:

El teatro (edificio)

= Application

Es la estructura que lo hace funcionar. Abre las puertas, prepara todo, y al final cierra.

El escenario (tarima)

= Stage

Es el marco físico donde ocurre la obra. En JavaFX, es la ventana.

La obra (lo que se presenta)

= Scene

Es el contenido que se muestra en el escenario. Puedes cambiar de obra sin demoler el teatro.

Los actores y utilería

= Node (controles)

Botones, campos de texto, etiquetas. Cada pieza visible es un nodo.

Esta analogía no es decorativa. Cada término (Application, Stage, Scene, Node) es una clase real de JavaFX que vas a usar en tu código.

Nivel 1

Application y launch() — El punto de arranque

Toda app JavaFX comienza con una clase que extiende Application. Esta clase tiene un método especial: start(Stage stage), que JavaFX llama automáticamente para que tú armes la interfaz.

public class MiApp extends Application {

    @Override
    public void start(Stage stage) {
        // Aquí armas la interfaz y la muestras
    }

    public static void main(String[] args) {
        launch(args);   // Arranca el sistema JavaFX
    }
}

¿Qué hace cada parte?

• extends Application — Convierte tu clase en una app JavaFX. Sin esto, nada funciona.
• launch(args) — Inicializa el motor de JavaFX y llama automáticamente a start(). Va siempre en el main.
• start(Stage stage) — El método que tú escribes. JavaFX te entrega un Stage (ventana) listo para usar.

Regla: Nunca creas un Stage con new Stage() para tu ventana principal. JavaFX te lo entrega como parámetro de start().

Nivel 2

Stage — La ventana

El Stage es la ventana del sistema operativo: tiene barra de título, botones de minimizar/maximizar/cerrar, y un espacio interior donde se muestra el contenido.

Stage (ventana)
Barra de título: "Mi Aplicación"
Tamaño, posición, ícono
← aquí va la Scene
(el contenido visual)

El Stage controla propiedades de la ventana, no del contenido:

stage.setTitle("Spotify Mini");      // Título en la barra
stage.setWidth(600);                  // Ancho de la ventana
stage.setHeight(400);                 // Alto de la ventana
stage.setResizable(false);            // Impedir que el usuario cambie el tamaño
stage.show();                         // Mostrar la ventana

El Stage es solo el marco. Sin una Scene asignada, la ventana aparece vacía. La relación es: stage.setScene(scene).

Nivel 3

Scene — El contenido de la ventana

La Scene es todo lo que ves dentro de la ventana. Para crearla, necesitas darle un nodo raíz (root): el contenedor que albergará todos los demás elementos.

VBox root = new VBox();                      // Nodo raíz (contenedor)
Scene scene = new Scene(root, 600, 400);     // Scene con tamaño 600x400

stage.setScene(scene);                       // Asignar al Stage
stage.show();                                // Mostrar
La Scene se encarga de:

El tamaño del área de contenido (ancho × alto)

Contener el nodo raíz y todo lo que esté dentro de él

Aplicar hojas de estilo CSS

La Scene NO se encarga de:

La barra de título (eso es del Stage)

Los botones minimizar/cerrar (eso es del Stage)

La posición de la ventana en pantalla (eso es del Stage)

¿Puedo cambiar la Scene? Sí. stage.setScene(otraScene) reemplaza todo el contenido sin cerrar la ventana. Es como cambiar de canal en un televisor.

Nivel 4

Node — La pieza fundamental

En JavaFX, todo lo que aparece en la Scene es un Node (nodo). Node es la clase padre de todos los elementos visuales.

Controles (interactivos)

Button — botón clickeable

Label — texto estático

TextField — campo de entrada

TextArea — texto multilínea

Contenedores (layouts)

VBox — apila verticalmente

HBox — alinea horizontalmente

GridPane — grilla filas/columnas

BorderPane — 5 zonas fijas

¿Por qué importa saber que todo es un Node?

Porque un contenedor (VBox) también es un Node. Eso significa que puedes poner un contenedor dentro de otro. Así se arman interfaces complejas: anidando contenedores como cajas dentro de cajas.

// Un VBox dentro de otro VBox — es válido porque ambos son Node
VBox formulario = new VBox(10, label, textField, boton);
VBox root = new VBox(20, titulo, formulario);     // formulario es un hijo de root
Visión completa

La jerarquía completa

Así se conecta todo, desde que arranca la app hasta que el usuario ve un botón en pantalla:

Application ← tu clase extiende esto
  │
  ├── launch(args) → arranca JavaFX
  │
  └── start(Stage) ← JavaFX te entrega la ventana
       │
       └── Scene ← tú la creas y la asignas al Stage
            │
            └── root (VBox, HBox, ...) ← nodo raíz
                 │
                 ├── Label
                 ├── TextField
                 └── Button

Resumen de responsabilidades:

• Application → arranca y coordina el ciclo de vida
• Stage → la ventana (marco, título, tamaño)
• Scene → el contenido visible (ancho, alto, CSS)
• Node raíz → el contenedor principal que organiza los hijos
• Nodos hijos → los controles que el usuario ve e interactúa

Contenedores

¿Qué es un contenedor (layout)?

Un contenedor es un Node especial cuyo trabajo es organizar la posición de otros nodos dentro de él. Cada tipo de contenedor organiza sus hijos de forma diferente.

Patrón universal para todos los contenedores:

1. Crear el contenedor: VBox root = new VBox();
2. Agregar hijos: root.getChildren().addAll(label, boton);
3. Usarlo como raíz de la Scene: new Scene(root, 600, 400);

JavaFX ofrece varios contenedores. La diferencia entre ellos es cómo organizan la posición de los hijos:

Contenedores lineales

VBox — en columna (vertical)

HBox — en fila (horizontal)

Contenedores estructurados

GridPane — grilla (filas × columnas)

BorderPane — 5 zonas fijas

Contenedores especiales

StackPane — capas apiladas

Group — sin organización

VBox col = new VBox(10);   // 10px entre hijos

Combinar: Puedes poner un HBox dentro de un VBox. Ejemplo: formulario vertical con una fila de botones horizontal al final. Es la combinación más usada.

Contenedor estructurado

GridPane — Grilla de filas y columnas

GridPane organiza los hijos en una tabla. Tú decides en qué celda (columna, fila) va cada elemento. Ideal para formularios tipo "etiqueta : campo".

GridPane form = new GridPane();
form.setHgap(10);     // Espacio horizontal entre columnas
form.setVgap(10);     // Espacio vertical entre filas

//                    columna, fila
form.add(lblNombre,      0,     0);
form.add(txtNombre,      1,     0);
form.add(lblEmail,       0,     1);
form.add(txtEmail,       1,     1);

A diferencia de VBox/HBox, en GridPane no usas getChildren().add(). Usas form.add(nodo, columna, fila) porque necesitas especificar la posición exacta.

Contenedor estructurado

BorderPane — 5 zonas fijas

BorderPane divide la ventana en 5 regiones: top, bottom, left, right y center. Cada zona acepta un solo nodo (que puede ser otro contenedor).

BorderPane layout = new BorderPane();
layout.setTop(menuBar);          // Barra superior
layout.setLeft(panelNavegacion); // Panel lateral
layout.setCenter(contenido);     // Área principal
layout.setBottom(barraEstado);   // Barra inferior

Cuándo usarlo: Cuando tu app tiene una estructura clásica con menú arriba, navegación a un lado y contenido en el centro. Es el layout típico de aplicaciones de escritorio.

Contenedores especiales

StackPane y Group

StackPane — Capas apiladas

StackPane pone todos sus hijos uno encima del otro, centrados. El último hijo agregado queda al frente.

StackPane capas = new StackPane();
capas.getChildren().addAll(
    fondo, marco, texto
);
StackPane
fondo
marco
texto

Group — Sin organización

Group no organiza nada. Los hijos se posicionan manualmente con coordenadas (x, y). Es el contenedor más básico.

Group grupo = new Group();
texto.setLayoutX(50);
texto.setLayoutY(100);
grupo.getChildren().add(texto);

En la práctica, casi nunca usarás Group. Usa VBox, HBox o BorderPane — dejan que JavaFX calcule las posiciones por ti.

Referencia rápida

¿Qué contenedor uso?

Usa esta tabla para decidir qué contenedor te conviene según lo que necesitas construir:

Necesitas... Usa Ejemplo típico
Elementos uno debajo del otro VBox Formulario simple, lista de controles
Elementos uno al lado del otro HBox Fila de botones, barra de herramientas
Etiqueta : campo alineados GridPane Formulario con labels y TextFields
Menú arriba + contenido + barra abajo BorderPane Layout principal de una app completa
Elementos apilados (superpuestos) StackPane Texto sobre imagen, indicador de carga
Posición libre (manual) Group Dibujo, animación (raro en apps normales)

Regla práctica para empezar: El 90% de las veces tu app necesita un VBox con un HBox para los botones. Cuando tengas formularios con etiquetas, usa GridPane. Cuando tu app crezca, envuelve todo en un BorderPane.

Todo junto

Ejemplo: armando una ventana paso a paso

Observa cómo cada pieza encaja. Este código abre una ventana con un formulario simple:

public class EjemploApp extends Application {

    @Override
    public void start(Stage stage) {
        // 1. Crear los controles (Node)
        Label titulo = new Label("Registro");
        TextField txtNombre = new TextField();
        txtNombre.setPromptText("Tu nombre");
        Button btnOk = new Button("Aceptar");

        // 2. Organizarlos en un contenedor (layout)
        VBox root = new VBox(12, titulo, txtNombre, btnOk);
        root.setStyle("-fx-padding: 24;");

        // 3. Crear la Scene con el contenedor como raíz
        Scene scene = new Scene(root, 350, 250);

        // 4. Asignar la Scene al Stage y mostrar
        stage.setTitle("Mi primera app");
        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}

El flujo siempre es el mismo:

Controles → dentro de un Layout → como raíz de una Scene → asignada al Stage → show()
