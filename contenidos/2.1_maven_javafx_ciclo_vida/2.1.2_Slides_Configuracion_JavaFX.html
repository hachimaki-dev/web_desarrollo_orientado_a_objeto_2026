Puente

Lo que ya sabes vs. lo que viene

Hasta ahora trabajaste con aplicaciones de consola: texto que entra por teclado y sale por pantalla. Ahora vamos a crear aplicaciones con ventanas.

Buena noticia: La lógica de tu programa (clases, ArrayList, constructores) no cambia. Solo cambia cómo el usuario interactúa con tu aplicación.

Concepto

¿Qué es JavaFX?

JavaFX es el framework oficial para crear interfaces gráficas (GUI) en Java. Reemplazó a Swing, que era viejo y limitado visualmente.

Swing (antes) 👴

Aspecto visual anticuado

No soporta CSS

Difícil de personalizar

Aún existe, pero ya no se recomienda para proyectos nuevos

JavaFX (ahora) 🚀

Aspecto visual moderno

Soporta CSS para estilos

Controles modernos listos para usar

Es lo que la industria usa para Java de escritorio

JavaFX no viene incluido en Java por defecto. Por eso necesitas Maven: para descargarlo como dependencia.

Configuración

El pom.xml para JavaFX

Este es el pom.xml completo que necesitas. En la guía de actividad lo vas a copiar tal cual.

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.spotify.mini</groupId>
    <artifactId>spotify-mini</artifactId>
    <version>1.0</version>

    <properties>
        <maven.compiler.source>21</maven.compiler.source>
        <maven.compiler.target>21</maven.compiler.target>
        <javafx.version>21.0.2</javafx.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.openjfx</groupId>
            <artifactId>javafx-controls</artifactId>
            <version>${javafx.version}</version>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.openjfx</groupId>
                <artifactId>javafx-maven-plugin</artifactId>
                <version>0.0.8</version>
                <configuration>
                    <mainClass>com.spotify.mini.SpotifyMiniApp</mainClass>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>

No lo memorices. Solo entiende que: javafx-controls es la dependencia que trae los botones, labels, etc. El plugin javafx-maven-plugin le dice a Maven cómo ejecutar tu app JavaFX.

Primera ventana

Tu primera ventana en JavaFX

Este es el código mínimo para abrir una ventana vacía:

package com.spotify.mini;

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class SpotifyMiniApp extends Application {

    @Override
    public void start(Stage stage) {
        VBox root = new VBox();                    // Contenedor principal
        Scene scene = new Scene(root, 600, 400);   // Escena de 600x400 px
        stage.setTitle("Spotify Mini");            // Título de la ventana
        stage.setScene(scene);                     // Asignar la escena
        stage.show();                              // Mostrar la ventana
    }

    public static void main(String[] args) {
        launch(args);    // Arranca JavaFX
    }
}

Línea por línea:

• Tu clase extiende Application — esto la convierte en una app JavaFX
• start(Stage stage) — JavaFX llama a este método al iniciar. El Stage es la ventana
• VBox — contenedor que apila elementos verticalmente
• Scene — el contenido que se muestra dentro de la ventana
• launch(args) — arranca todo el sistema JavaFX

¿Cómo se ejecuta? En la terminal con mvn javafx:run, o creando una clase Main.java con SpotifyMiniApp.main(args); para usar el botón "Run Java" / F5 de VS Code.

Controles básicos

Label — Mostrar texto

Un Label muestra texto en la ventana. Es el equivalente visual de System.out.println().

import javafx.scene.control.Label;

// Crear un label
Label titulo = new Label("Spotify Mini 🎧");
Label subtitulo = new Label("Gestiona tu colección de canciones");

// Agregar al contenedor
VBox root = new VBox(10);    // 10 = espacio entre elementos
root.getChildren().addAll(titulo, subtitulo);

Controles básicos

Button — Ejecutar acciones

Un Button ejecuta código cuando el usuario hace clic. Es el reemplazo del menú switch de la consola.

import javafx.scene.control.Button;

// Crear un botón
Button btnAgregar = new Button("Agregar Canción");

// Definir qué pasa al hacer clic
btnAgregar.setOnAction(e -> {
    System.out.println("Botón clickeado!");
    // Aquí irá la lógica real
});

¿Qué es e -> { ... }?

Es una expresión lambda — una forma corta de escribir "cuando ocurra el evento, ejecuta este código". La e es el evento (no lo usamos por ahora, pero debe estar).

Controles básicos

TextField — Entrada de texto

Un TextField permite al usuario escribir texto. Es el reemplazo de Scanner.

import javafx.scene.control.TextField;

// Crear campo de texto
TextField txtTitulo = new TextField();
txtTitulo.setPromptText("Nombre de la canción");  // Texto gris de ayuda

// Obtener lo que el usuario escribió
String titulo = txtTitulo.getText();

// Limpiar el campo después de usarlo
txtTitulo.clear();

Ejemplo completo

Juntando Label + TextField + Button

@Override
public void start(Stage stage) {
    // Controles
    Label titulo = new Label("Spotify Mini 🎧");
    TextField txtCancion = new TextField();
    txtCancion.setPromptText("Nombre de la canción");
    Button btnAgregar = new Button("Agregar");

    // Evento del botón
    btnAgregar.setOnAction(e -> {
        String cancion = txtCancion.getText();
        System.out.println("Canción agregada: " + cancion);
        txtCancion.clear();
    });

    // Contenedor vertical con 10px de espacio
    VBox root = new VBox(10, titulo, txtCancion, btnAgregar);
    root.setStyle("-fx-padding: 20;");

    // Escena y Stage
    Scene scene = new Scene(root, 400, 300);
    stage.setTitle("Spotify Mini");
    stage.setScene(scene);
    stage.show();
}

Estilo visual

CSS en JavaFX

JavaFX usa CSS para definir el aspecto visual de los controles. Es muy similar al CSS de páginas web, pero con algunas diferencias.

Igual que en web

Selectores por tipo, clase e id

Propiedades como color, padding, font-size

Pseudoclases como :hover y :focused

Se escribe en un archivo .css externo

Diferente a la web

Las propiedades llevan el prefijo -fx-

Ejemplo: -fx-background-color en vez de background-color

Los selectores de tipo usan el nombre de la clase Java: .label, .button, .text-field

¿Por qué CSS? Separar el diseño del código. Puedes cambiar toda la apariencia de tu app sin tocar una línea de Java.

CSS JavaFX

Archivo CSS externo y selectores

El archivo CSS se guarda en src/main/resources/styles.css y se vincula a la escena desde Java:

// En tu método start(), después de crear la Scene:
scene.getStylesheets().add(
    getClass().getResource("/styles.css").toExternalForm()
);

Y en styles.css:

/* Selector por tipo: aplica a TODOS los Label */
.label {
    -fx-text-fill: #ffffff;
}

/* Selector por clase CSS (la asignas desde Java) */
.titulo-principal {
    -fx-font-size: 24px;
    -fx-font-weight: bold;
    -fx-text-fill: #1db954;
}

/* Selector por ID */
#btn-agregar {
    -fx-background-color: #1db954;
    -fx-text-fill: #ffffff;
    -fx-background-radius: 20;
    -fx-cursor: hand;
}

/* Pseudoclase: hover (cuando el mouse está encima) */
#btn-agregar:hover {
    -fx-background-color: #1ed760;
}

/* Pseudoclase: focused (cuando el campo tiene foco) */
.text-field:focused {
    -fx-border-color: #1db954;
    -fx-border-width: 2;
}

Asignar clase o ID desde Java:

titulo.getStyleClass().add("titulo-principal");
btnAgregar.setId("btn-agregar");
