Colecciones y Excepciones

Guía paso a paso para agregar colecciones y manejo de errores al proyecto Instagram POO.

Requisitos previos

Antes de comenzar, asegúrate de tener las clases Publicacion (padre), Historia, Reel y Post (hijas) implementadas y funcionando. Si no las tienes, revisa la guía 1.3.4 y el diagrama UML 1.3.6.

1
Crea la colección polimórfica en Main.java

Abre tu archivo Main.java. Al inicio del método main, declara una lista que almacene publicaciones de cualquier tipo:

import java.util.ArrayList;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        ArrayList<Publicacion> feed = new ArrayList<>();
        boolean ejecutando = true;

        // El menú se construirá en los pasos siguientes
    }
}

¿Por qué ArrayList<Publicacion>? Al declarar la lista con el tipo padre, puede almacenar objetos de cualquier clase hija: Historia, Reel o Post. Esto es polimorfismo aplicado a colecciones.

Pregunta: ¿Qué pasaría si declaras ArrayList<Historia> en vez de ArrayList<Publicacion>? ¿Podrías agregar un Reel?

3
Implementa "Crear publicación" con submenú

Crea el método que muestra un submenú para elegir el tipo de publicación y solicita los datos específicos:

private static void crearPublicacion(Scanner scanner, ArrayList<Publicacion> feed) {
    System.out.println("\n--- Tipo de publicación ---");
    System.out.println("1. Historia");
    System.out.println("2. Reel");
    System.out.println("3. Post");
    System.out.print("Seleccione: ");
    String tipo = scanner.nextLine().trim();

    // Datos comunes (del padre)
    System.out.print("ID: ");
    String id = scanner.nextLine();
    System.out.print("Autor: ");
    String autor = scanner.nextLine();

    switch (tipo) {
        case "1":
            System.out.print("¿Mejores amigos? (true/false): ");
            boolean mejoresAmigos = Boolean.parseBoolean(scanner.nextLine());
            feed.add(new Historia(id, autor, mejoresAmigos));
            System.out.println("Historia creada.");
            break;

        case "2":
            int duracion = 15;
            try {
                System.out.print("Duración en segundos (3-90): ");
                duracion = Integer.parseInt(scanner.nextLine());
            } catch (NumberFormatException e) {
                System.out.println("Duración no válida. Se usará 15 segundos.");
            }
            System.out.print("Nombre del audio: ");
            String audio = scanner.nextLine();
            feed.add(new Reel(id, autor, duracion, audio));
            System.out.println("Reel creado.");
            break;

        case "3":
            System.out.print("Pie de foto: ");
            String pieFoto = scanner.nextLine();
            System.out.print("Ubicación: ");
            String ubicacion = scanner.nextLine();
            feed.add(new Post(id, autor, pieFoto, ubicacion));
            System.out.println("Post creado.");
            break;

        default:
            System.out.println("Tipo no válido.");
            break;
    }
}

Observa: Al crear el Reel, se usa try-catch para manejar el caso en que el usuario escriba texto en vez de un número. Si falla, se asigna un valor por defecto.

Pregunta: ¿Por qué feed.add(new Historia(...)) funciona si la lista es de tipo Publicacion y estamos agregando una Historia?

4
Implementa "Ver Feed" con for-each polimórfico
private static void mostrarFeed(ArrayList<Publicacion> feed) {
    if (feed.isEmpty()) {
        System.out.println("El feed está vacío. Crea una publicación primero.");
        return;
    }

    System.out.println("\n--- FEED DE PUBLICACIONES ---");
    for (int i = 0; i < feed.size(); i++) {
        System.out.println("[" + i + "]");
        feed.get(i).mostrarDetalle();
        System.out.println("---------------------------");
    }
    System.out.println("Total de publicaciones: " + feed.size());
}

Polimorfismo en acción: mostrarDetalle() ejecuta la versión correcta según el tipo real del objeto: Historia muestra duración y vistas, Reel muestra audio y reproducciones, Post muestra pie de foto y ubicación.

5
Implementa "Dar Like" con validación completa

Este método combina validación preventiva (if para lista vacía y rango) con validación reactiva (try-catch para parseo):

private static void darLike(Scanner scanner, ArrayList<Publicacion> feed) {
    if (feed.isEmpty()) {
        System.out.println("El feed está vacío.");
        return;
    }

    // Mostrar opciones disponibles
    System.out.println("\n--- Publicaciones disponibles ---");
    for (int i = 0; i < feed.size(); i++) {
        System.out.println(i + ". [" + feed.get(i).getId() + "] por " + feed.get(i).getAutor());
    }

    try {
        System.out.print("Índice de la publicación: ");
        int indice = Integer.parseInt(scanner.nextLine());

        if (indice < 0 || indice >= feed.size()) {
            System.out.println("Índice fuera de rango. Rango válido: 0 a " + (feed.size() - 1));
            return;
        }

        feed.get(indice).darLike();
        System.out.println("Like registrado. Total de likes: " + feed.get(indice).getLikes());

    } catch (NumberFormatException e) {
        System.out.println("Error: debe ingresar un número entero.");
    }
}

Pregunta: ¿Qué pasaría si no tuvieras el try-catch y el usuario escribe "abc" como índice?

6
Implementa "Buscar publicación por ID"

Patrón de búsqueda lineal: recorrer la lista comparando hasta encontrar.

private static void buscarPorId(Scanner scanner, ArrayList<Publicacion> feed) {
    if (feed.isEmpty()) {
        System.out.println("El feed está vacío.");
        return;
    }

    System.out.print("Ingrese el ID a buscar: ");
    String idBuscado = scanner.nextLine().trim();

    // Búsqueda lineal
    Publicacion encontrada = null;
    for (Publicacion pub : feed) {
        if (pub.getId().equals(idBuscado)) {
            encontrada = pub;
            break; // Ya la encontramos, no es necesario seguir
        }
    }

    if (encontrada != null) {
        System.out.println("\nPublicación encontrada:");
        encontrada.mostrarDetalle();
    } else {
        System.out.println("No se encontró una publicación con ID: " + idBuscado);
    }
}

Patrón: Declarar una variable null antes del bucle. Si la encontramos, la asignamos y salimos con break. Después del bucle, verificamos si sigue siendo null.

7
Implementa "Estadísticas del Feed" con HashMap

Usa un HashMap para contar cuántas publicaciones hay de cada tipo:

import java.util.HashMap;

private static void mostrarEstadisticas(ArrayList<Publicacion> feed) {
    if (feed.isEmpty()) {
        System.out.println("El feed está vacío.");
        return;
    }

    // Contar publicaciones por tipo usando HashMap
    HashMap<String, Integer> conteo = new HashMap<>();
    int totalLikes = 0;

    for (Publicacion pub : feed) {
        // Obtener el nombre de la clase real del objeto
        String tipo = pub.getClass().getSimpleName(); // "Historia", "Reel" o "Post"
        conteo.put(tipo, conteo.getOrDefault(tipo, 0) + 1);
        totalLikes += pub.getLikes();
    }

    // Mostrar resultados
    System.out.println("\n--- ESTADÍSTICAS DEL FEED ---");
    System.out.println("Total de publicaciones: " + feed.size());
    System.out.println("Total de likes: " + totalLikes);

    if (!feed.isEmpty()) {
        double promedio = (double) totalLikes / feed.size();
        System.out.printf("Promedio de likes: %.1f%n", promedio);
    }

    System.out.println("\nPor tipo:");
    for (String tipo : conteo.keySet()) {
        System.out.println("  " + tipo + ": " + conteo.get(tipo));
    }
}

getOrDefault(clave, 0): Si la clave existe, retorna su valor. Si no existe, retorna 0. Esto evita un NullPointerException al intentar sumar sobre un valor null.

Pregunta: ¿Qué ventaja tiene usar getOrDefault(tipo, 0) + 1 en vez de verificar con containsKey primero?

8
Envuelve el menú con try-catch general

Agrega un try-catch alrededor del contenido del while para que ningún error imprevisto detenga el programa:

while (ejecutando) {
    try {
        System.out.println("\n=== INSTAGRAM CONSOLE APP ===");
        System.out.println("1. Crear publicación");
        System.out.println("2. Ver Feed completo");
        System.out.println("3. Dar Like a una publicación");
        System.out.println("4. Buscar publicación por ID");
        System.out.println("5. Estadísticas del Feed");
        System.out.println("6. Salir");
        System.out.print("Seleccione una opción: ");

        String opcion = scanner.nextLine().trim();

        switch (opcion) {
            case "1": crearPublicacion(scanner, feed); break;
            case "2": mostrarFeed(feed); break;
            case "3": darLike(scanner, feed); break;
            case "4": buscarPorId(scanner, feed); break;
            case "5": mostrarEstadisticas(feed); break;
            case "6":
                System.out.println("¡Hasta pronto! 🛸");
                ejecutando = false;
                break;
            default:
                System.out.println("Opción no válida.");
                break;
        }
    } catch (Exception e) {
        System.out.println("Error inesperado: " + e.getMessage());
        System.out.println("El programa continúa funcionando.");
    }
}

Menú defensivo: Este try-catch general es una red de seguridad. Cada método individual ya maneja sus propios errores específicos, pero si algún caso no previsto ocurre, este catch lo atrapa sin romper el menú.
