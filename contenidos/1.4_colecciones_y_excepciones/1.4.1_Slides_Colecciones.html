Colecciones

ArrayList, HashMap y cómo organizar datos dinámicos en Java.

🛸
Motivación

El problema con los arrays

Un array en Java tiene tamaño fijo. Se define al crear y no puede cambiar.

String[] nombres = new String[3]; // Solo 3 posiciones
nombres[0] = "Ana";
nombres[1] = "Pedro";
nombres[2] = "Luis";
// nombres[3] = "María"; → ERROR: ArrayIndexOutOfBoundsException
Limitaciones del array

Tamaño fijo al momento de la creación.

No tiene métodos para buscar, eliminar o contar.

Insertar o eliminar en el medio requiere desplazar elementos manualmente.

Lo que necesitamos

Una estructura que crezca y se reduzca automáticamente.

Con métodos integrados para agregar, buscar, eliminar.

Que funcione con cualquier tipo de objeto.

Concepto

ArrayList<T>

Una lista dinámica que crece automáticamente. Pertenece al paquete java.util.

import java.util.ArrayList;

// Declarar y crear
ArrayList<String> nombres = new ArrayList<>();

// Agregar elementos (la lista crece sola)
nombres.add("Ana");
nombres.add("Pedro");
nombres.add("Luis");
nombres.add("María"); // Sin problema — crece automáticamente

Tipo genérico <T>

El tipo entre < > indica qué tipo de objetos almacena la lista. Solo acepta objetos, no primitivos. Para int se usa Integer, para double se usa Double.

Ejemplo genérico

ArrayList en acción — Lista de animales

import java.util.ArrayList;

public class EjemploLista {
    public static void main(String[] args) {
        ArrayList<String> animales = new ArrayList<>();

        // Agregar
        animales.add("Perro");
        animales.add("Gato");
        animales.add("Pato");

        // Consultar
        System.out.println("Total: " + animales.size());     // 3
        System.out.println("Primero: " + animales.get(0));    // Perro
        System.out.println("Tiene Gato: " + animales.contains("Gato")); // true

        // Modificar
        animales.set(1, "León");  // Reemplaza "Gato" por "León"

        // Eliminar
        animales.remove(0);      // Elimina "Perro"

        System.out.println(animales); // [León, Pato]
    }
}
Aterrizado al proyecto

ArrayList polimórfico — Caso Instagram

La lista almacena objetos de tipo Publicacion (padre). Pero los objetos reales pueden ser Historia, Reel o Post.

import java.util.ArrayList;

ArrayList<Publicacion> feed = new ArrayList<>();

// Agregar diferentes tipos de publicaciones
feed.add(new Historia("H1", "carlos", true));
feed.add(new Reel("R1", "ana", 30, "Trending Audio"));
feed.add(new Post("P1", "pedro", "Vacaciones", "Viña"));

System.out.println("Publicaciones en el feed: " + feed.size()); // 3

Colección polimórfica: La lista es de tipo Publicacion, pero almacena objetos hijos. Cada elemento mantiene su comportamiento real gracias al polimorfismo.

Iteración

Recorrer con for tradicional (por índice)

Usar cuando necesitas el número de posición del elemento.

for (int i = 0; i < feed.size(); i++) {
    System.out.println("Posición " + i + ":");
    feed.get(i).mostrarDetalle();
}
Usa for-each cuando:

Solo necesitas leer cada elemento.

No importa la posición.

No vas a modificar la lista durante el recorrido.

Usa for tradicional cuando:

Necesitas mostrar o usar el índice.

Necesitas acceder a posiciones específicas.

Vas a eliminar elementos durante el recorrido.

Patrón de búsqueda

Buscar un elemento en la lista

Patrón de búsqueda lineal: recorrer la lista comparando hasta encontrar el elemento deseado.

// Buscar publicación por ID en el feed de Instagram
public static Publicacion buscarPorId(ArrayList<Publicacion> feed, String id) {
    for (Publicacion pub : feed) {
        if (pub.getId().equals(id)) {
            return pub; // Encontrada
        }
    }
    return null; // No existe
}

// Uso:
Publicacion resultado = buscarPorId(feed, "R1");
if (resultado != null) {
    resultado.mostrarDetalle();
} else {
    System.out.println("Publicación no encontrada.");
}
Patrón de filtrado

Filtrar elementos de una lista

Recorrer + condición + acumular en una nueva lista.

// Filtrar solo las Historias activas del feed
ArrayList<Publicacion> historiasActivas = new ArrayList<>();

for (Publicacion pub : feed) {
    if (pub instanceof Historia) {
        Historia h = (Historia) pub;  // Casting explícito
        if (h.isEstaActiva()) {
            historiasActivas.add(h);
        }
    }
}

System.out.println("Historias activas: " + historiasActivas.size());

instanceof verifica el tipo real del objeto. Después del check, se hace casting para acceder a los métodos específicos de la clase hija.

Concepto

HashMap<K, V>

Estructura que almacena pares de clave → valor. Cada clave es única. Pertenece a java.util.

Clave (K)
→
Valor (V)
import java.util.HashMap;

// Clave: String (nombre de ciudad) → Valor: Integer (temperatura)
HashMap<String, Integer> temperaturas = new HashMap<>();

temperaturas.put("Santiago", 18);
temperaturas.put("Valparaíso", 15);
temperaturas.put("Temuco", 10);

System.out.println(temperaturas.get("Santiago")); // 18

Analogía: un diccionario donde buscas por la palabra (clave) para obtener la definición (valor).

Aterrizado al proyecto

HashMap en Instagram — Indexar por ID

import java.util.HashMap;

// Mapa para buscar publicaciones rápidamente por su ID
HashMap<String, Publicacion> indicePorId = new HashMap<>();

// Agregar publicaciones al mapa
indicePorId.put("H1", new Historia("H1", "carlos", true));
indicePorId.put("R1", new Reel("R1", "ana", 30, "Audio Viral"));
indicePorId.put("P1", new Post("P1", "pedro", "Vacaciones", "Viña"));

// Buscar por ID (sin recorrer la lista completa)
if (indicePorId.containsKey("R1")) {
    Publicacion pub = indicePorId.get("R1");
    pub.mostrarDetalle();
} else {
    System.out.println("ID no encontrado.");
}

Ventaja: Con HashMap, buscar por clave es prácticamente instantáneo. Con ArrayList, hay que recorrer elemento por elemento.

Iteración

Recorrer un HashMap

HashMap<String, Integer> likesPorAutor = new HashMap<>();
likesPorAutor.put("carlos", 45);
likesPorAutor.put("ana", 120);
likesPorAutor.put("pedro", 78);

// Opción 1: Recorrer claves
for (String autor : likesPorAutor.keySet()) {
    System.out.println(autor + " tiene " + likesPorAutor.get(autor) + " likes");
}

// Opción 2: Recorrer pares clave-valor (más eficiente)
for (Map.Entry<String, Integer> entry : likesPorAutor.entrySet()) {
    System.out.println(entry.getKey() + " → " + entry.getValue());
}

Para usar Map.Entry, agrega import java.util.Map; en los imports.

Búsqueda Recorrer hasta encontrar (lento en listas grandes) Acceso directo por clave (rápido)

Colección + Polimorfismo

ArrayList polimórfico

La combinación de colecciones y polimorfismo es una de las herramientas más poderosas de la POO.

ArrayList<Publicacion> feed = new ArrayList<>();
feed.add(new Historia("H1", "carlos", false));
feed.add(new Reel("R1", "ana", 60, "Trending"));
feed.add(new Post("P1", "pedro", "Hola mundo", "Santiago"));

// UNA sola línea de código recorre TODOS los tipos
for (Publicacion pub : feed) {
    pub.mostrarDetalle();  // Cada objeto ejecuta SU versión
}
Principio clave: No necesitas saber qué tipo de publicación es cada elemento. El polimorfismo se encarga de ejecutar el método correcto automáticamente.

CRUD con ArrayList — Instagram

ArrayList<Publicacion> feed = new ArrayList<>();

// CREATE — Agregar
feed.add(new Post("P1", "carlos", "Mi primera foto", "Santiago"));

// READ — Leer por índice
Publicacion primera = feed.get(0);
primera.mostrarDetalle();

// UPDATE — Dar like a una publicación
feed.get(0).darLike();

// DELETE — Eliminar por índice
feed.remove(0);

// Verificar
System.out.println("Feed vacío: " + feed.isEmpty()); // true
Patrón de acumulación

Contar, sumar y promediar sobre una colección

ArrayList<Publicacion> feed = new ArrayList<>();
// ... (feed ya tiene publicaciones con likes)

// CONTAR publicaciones de un autor
int totalCarlos = 0;
for (Publicacion pub : feed) {
    if (pub.getAutor().equals("carlos")) {
        totalCarlos++;
    }
}

// SUMAR todos los likes del feed
int totalLikes = 0;
for (Publicacion pub : feed) {
    totalLikes += pub.getLikes();
}

// PROMEDIO de likes
double promedio = (feed.isEmpty()) ? 0 : (double) totalLikes / feed.size();

Resumen

Lo que aprendimos

ArrayList<T>

Lista dinámica ordenada por posición. Ideal para el feed de Instagram.

HashMap<K, V>

Mapa clave-valor para búsquedas rápidas. Ideal para indexar por ID.

Iteración

for-each para leer todos. for tradicional cuando necesitas el índice.

Patrones

Búsqueda lineal, filtrado, CRUD y acumulación sobre colecciones.

Colecciones + Polimorfismo = poder recorrer objetos de diferentes tipos con un único bucle y un único método.
